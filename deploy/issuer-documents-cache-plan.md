# 투자회사 공식 원문 비공개 캐시 적용 계획

아직 운영에 적용하지 않은 설정입니다. `issuer-documents.override.yaml`은 서버의 캐시 환경변수와 비공개 바인드 마운트만 추가합니다. 원본 PDF를 웹에 배포하거나 재배포 권리를 주장하지 않습니다.

1. 실행 중인 수집 작업이 0이고, 승인된 운영 커밋의 계보와 배포 대상 이미지가 일치하는지 확인합니다.
2. 정확한 대상 이미지의 서버 사용자 UID/GID를 확인한 뒤 `/opt/alfinder/issuer-documents` 소유권을 준비합니다. 숫자 UID는 추정하지 않습니다.
3. 기존 Compose 설정·사용자 설정은 보존하고 `.env`의 `COMPOSE_FILE`에 기존 파일과 이 override를 함께 지정합니다. 환경변수 값과 비밀은 출력하지 않습니다.
4. 적용 전후 유효 Compose를 비교하여 서버의 `ISSUER_DOCUMENT_CACHE_DIR`와 캐시 마운트 이외의 변경이 없는지 검사합니다. 캐시 경로의 심볼릭 링크·잘못된 권한은 적용 전에 거부합니다.
5. 이후 승인된 정상 배포 절차에서 적용하고, Source SHA와 다운로드 시각, 재시작 뒤 원본 보존을 확인합니다. 운영 적용은 이 변경의 검증 범위에 포함되지 않습니다.

수집 대상은 검증된 고정 문서 15개(연간 12개와 최신 3개)입니다. KB발해인프라 2021~2023 자체 원문은 미확보 상태이며 자동 발견·재무 숫자 추출·5개년 수집 완료를 의미하지 않습니다.
