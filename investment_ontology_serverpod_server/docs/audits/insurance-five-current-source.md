# 검산된 보험·투자회사 5개 원문 프로필

운영 읽기 전용 확인에서 3접수의 양 기준은 failed, 일반/API attempts3와 publicattempt3이었다. registry197에는 해당 접수가 등록되지 않았다. 재시도 초기화 없이 고정 원문 once-cache로 다음 5개만 수집할 수 있도록 등록한다.

|---|---|---|---|
| 현대해상화재보험 / FY2021.12 | 20220816002204 | CFS, OFS | 각 BS/CIS/CE/CF 원 |

| 우리기술투자 / FY2022.12 | 20230322000851 | CFS만 | 각 BS/CIS/CE/CF 원 |

원문 shell/cover/body URI와 SHA, 요청 법인코드·현재 회사명·접수·basis·기간을 모두 고정한다. 현재 이름은 운영 장부의 명칭과 같으며 별칭/역사 이름 허용은 추가하지 않는다. 현대해상은 기재정정 대상 접수 자체의 원문 숫자이며 원접수 숫자로 바꾸지 않는다.

직접 자산·부채·자본·전체 영업수익·영업손익·전체 순손익·CFO 7행만 저장한다. BS 등식, CE 실제 당기초/말·전체 NI/E 및 전기 BS 자본, CF O/I/F/FX/증감/기초/말과 BS 당기·전기 현금을 각각 검산한다. 각 표의 실제 시작·종료일이 인쇄되어 `flowCaptionPrintedStart:true`다. whole 순익은 owners/NCI 구성열이나 조정 후 이익 대신 직접 전체 셀을 사용한다. 원문 값·명칭·연도·주석 숫자·표제는 고치지 않는다.

백만원의 FinancialFact는 기존 KRW 저장 계약에 따라 1,000,000을 곱한다. 원문 인쇄 숫자 문자열/currentCell, printedUnit, multiplier, 표·행·열 및 원문 SHA를 Source 감사 행에 남긴다. 이 경로는 인쇄 단위를 그대로 저장하는 사업본문 DocumentFact와 별개다. 7개 핵심계정만 복구하며 `fullStatementCollected:false`, capex는 미수집으로 null을 유지한다. 원문에 capex가 없다고 주장하지 않는다.
