# 더콘텐츠온 말일 표제의 독립 연간기간 검증

OFS 원문 4개만 지원한다: 20220323000557(FY2021), 20240321001908(FY2023), 20250321000964(FY2024), 20260323001088(FY2025), 법인코드 00991225.

각 원문은 BS·손익·CF 표제에 말일 `현재`만 인쇄한다. 시작일을 손익·CF 표제에서 읽었다고 기록하지 않는다. 정확한 연간 표지, 같은 현재 기수와 말일, 현재 연도의 CE `01.01(당기초)`→`12.31(당기말)` 사이 유일 전체 순손익 행으로 독립 기간을 증명한다. FY2021의 앞선 두 CE 연도는 실제 날짜로 제외한다.

검증은 CE 구성항목/전체 자본 합계, CE/BS 당기 및 전기 자본, BS 자산=부채+자본, CE/CIS 전체 순손익, CF 기초·기말과 BS 전기·당기 현금, O+I+F=증감 및 기초+증감=기말을 모두 요구한다. CE의 `-`는 합계 검산에만 쓰며 숫자로 저장하지 않는다. 원문 인쇄 8계정은 별도 직접 셀 추출 증거와 비교한다. 출처 URI·원접수·법인·기간·basis·표지와 본문 SHA가 고정돼 있으며 다른 회사/접수/기간에는 적용하지 않는다.

`supportingPeriodEvidence.flowCaptionPrintedStart=false`, 시작 근거는 표지와 CE 인쇄 연초다. 원문 금액·표제·날짜를 수정하지 않는다. immutable cache는 기존 public 3회 한도를 리셋하지 않고 검증된 새 manifest당 기존 일회 재검증 계약만 이용한다. 일반 6계정 경로는 변경하지 않는다.

썬테크 FY2022의 CE 연초는 2021, 본시스템즈 FY2025의 CE 당기말은 2025.06.30이다. 이 두 충돌 원문은 이 profile 대상이 아니며 기존 거부를 유지한다. DB 및 운영 수집 결과는 별도 슬롯 검증 전까지 주장하지 않는다.

검증 결과: 순수126개 통과, 정적 분석 오류 없음. 격리 정상 수집 큐 4개 모두 통과했다. 각 원문의 직접8행·기간·Source URI/SHA와 8행의 독립 기간 provenance 저장을 확인했고, API0·시도 횟수·일회 replay audit 및 반대 basis의 **합성 보존용 fixture**는 불변이었다. 이 결과는 운영 수집 완료나 실제 반대 basis 원문 검증을 의미하지 않는다.
