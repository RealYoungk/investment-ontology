회사개요의 같은 문단에서 명칭 표제와 BR 다음 직접 선언이 인쇄되어 있습니다. 기존 BR 분리 규칙과 직접 명칭 규칙이 이를 이미 지원하며, 그 문법은 변경하지 않았습니다. 현재 장부명과 실제 표지·직접 선언 명칭을 각각 원문 근거에 남깁니다.
