# digest_audit — 사업의 내용 요약 검산

`BusinessDigestSection`의 요약 문장에 적힌 매출·영업이익·순이익·증감률을 `financial_fact`(DART 재무제표)와
대조하는 스크립트입니다. 요약은 세션에서 사람이(모델이) 읽어 넣으므로 숫자를 잘못 읽거나 단위를 놓칠 수
있고, 사업의 내용 표 자체가 연결재무제표와 다른 기준(내부거래 포함 부문 합계, 종속회사 제외 본사 값,
품목 합계)인 경우가 많습니다. 새 요약을 넣은 뒤 한 번 돌려 찍힌 줄을 보고 고칩니다.

```
python3 tool/digest_audit/digest_audit.py             # FY2025, 내장 PostgreSQL 소켓 /tmp/iopg
python3 tool/digest_audit/digest_audit.py --year 2026
```

출력 한 줄이 곧 살펴볼 항목입니다 (기준 대비 차이, 회사, 문서 id, 요약 속 문구, 재무제표 값).
2026-09-22 첫 실행에서 매출 256건 중 8건을 고쳤고, 이익 61건·증감률 208건은 자회사·부문 값이라 그대로 두었습니다.

- 찍혔지만 맞는 경우: 자회사 값(메리츠증권·한국투자증권), 부문 값(삼성물산 바이오, 한화비전 시큐리티),
  전기 값이 재무제표에서 재작성된 경우(한화에어로스페이스·오리온홀딩스). 요약에 그 기준이 적혀 있으면 됩니다.
- 고쳐야 하는 경우: 표의 "합 계"를 연결 매출이라고 적은 것(BGF리테일·HDC), 전기 칸에 다른 값을 적은 것(이수페타시스),
  단순 오독(리가켐). 고칠 때는 `ai.submitDigest`로 **그 문서의 절 전부**를 다시 넣습니다 (절이 통째로 바뀜).
