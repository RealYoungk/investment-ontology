# 공식 시장 지표 공급원 갱신

원/달러는 한국수출입은행 AP01의 USD deal_bas_r(일별 매매기준율)를 사용한다. EXIM_USDKRW는 ECB/연준 환율과 연결하지 않는 독립 시계열이다. 과거 공식 관측값 736개(790회 요청)를 assets/macro/exim_usdkrw.json에 보관했다. 2026-10-02 최신값 1359.6원/달러. 재현 스크립트 scripts/fetch_exim_history.py는 호출 상한850, 인증 URL 출력 금지, 실패 시 전체 파일 교체 금지를 적용한다.

로컬 shared.koreaEximApiKey, 운영 SERVERPOD_PASSWORD_koreaEximApiKey를 ApiSecret으로 읽는다. 비밀값은 소스·Source·브라우저 응답·이미지에 포함되지 않는다. 최근7일 중 평일만 시간당 갱신(최대120회/일), 과거자료는 캐시 재사용한다. 운영 MACRO_CACHE_DIRECTORY는 전용 볼륨으로 서버 재생성에도 유지한다. 결측일은 보간하거나 0으로 채우지 않는다.

국채2년/10년은 미국 재무부 연별 공식 XML을 공유 조회하고, 장애 시 동일 만기의 FRED 시계열로 대체한다. EIA API 어댑터도 있지만 별도 EIA 키 미발급으로 원유는 FRED 공식 배포를 유지한다. 광의 달러지수는 연준 주간 발표/FRED 배포를 유지하며 ICE DXY와 구별한다.

원천·기준일·수신시간·매매기준율 정의·발표주기를 화면에서 설명한다. 성공캐시1시간, 실패5분, 동시조회중복제거, 이전 성공값 보존. 수출입은행 장애 시 다른 환율 정의로 대체하지 않는다.
