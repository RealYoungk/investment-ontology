# 업종과 실적 상태에 따른 지표 설계

2026-09-30. 사용자 요구: 특정 지표 두 개 추가가 아니라 회사에 적절한 비교 도구를 제공한다.

## 읽는 순서

기업 상단 그리드는 추천 기본값으로 6개 핵심 지표를 보여준다. 그리드 바로 위에서 추천 / 가격 / 성장·수익성 / 현금·투자를 선택하면 그 자리의 지표가 바뀐다. 시가총액은 유지한다. 지표를 누르면 현재 탭에서 모달로 의미·식·기간·원천 입력을 확인한다. 재무 탭은 실적 추이와 재무제표 역할에 집중하며 별도 지표 탐색을 중복 표시하지 않는다. 지표를 늘려 상단을 채우거나 자동 저평가 점수로 만들지 않는다. 기존 지표도 가격 그룹 등에서 접근할 수 있다. 값이 없으면 필요한 항목/기간을 적는다.

| 사업/상태 | 첫 비교 | 보완할 축 | 피할 자동화 |
|---|---|---|---|
| 제조·운송·설비 | POR, PER, 가능한 경우 EV/EBITDA | 마진, 설비투자/매출, FCF 수익률 | 감가상각을 현금 지출이 아니므로 무시하는 해석 |
| 금융 | PBR와 ROE, PER, ROA | 이익 성장, 배당 | 예수금 포함 부채를 일반기업 EV/부채비율로 비교 |
| 적자 기업 | PSR, 매출 성장, 영업마진 | 현금, FCF 수익률 | 음수 PER, 적자→흑자 성장률, 매출 없는 바이오의 PSR |
| 소프트웨어·일반 성장 | PER와 PSR, 매출 성장 | 마진, FCF 수익률 | 매출 성장만으로 저평가 판정 |
| 리츠·인프라 | PBR, 현금 등 현재 확인 가능한 값 | 주주환원 탭 배당, 추후 FFO/NAV | 순이익이나 PBR를 부동산 NAV/분배가능이익으로 간주 |
| 지주사·복합기업 | 일반 재무는 보조 | 추후 상장/비상장 자회사 가치, 순차입금의 SOTP | 장부자본을 NAV로 표시 |
| 은행·보험 업종 고유 지표 | 추후 NIM/CET1, CSM/K-ICS | 보고서 정의·규제 기준·공시 단위 | 범용 재무제표 금액으로 근사 |
| 매출 전 바이오 | 보유 현금과 지출, 임상/허가 단계 | 추후 현금 소진과 마일스톤 | 임상 성공확률·rNPV를 자동 추정 |

분류는 금융/자산운용을 우선하고, 실제 비양수 TTM 순이익, 설비 업종, 일반기업 순이다. 자료 없음은 적자로 분류하지 않는다. 분류는 기본 읽기 순서이며 정교한 기업별 추천의 완료를 의미하지 않는다. 투자 추천이 아니다.

## 구현한 계산

- 기존 PER, PBR, ROE, 영업이익률, 부채비율, FCF, FCF 수익률 유지.
- PSR = 시가총액 / TTM 매출. POR = 시가총액 / TTM 영업이익. P/OCF = 시가총액 / TTM 영업현금흐름. 각 분모 양수일 때만 계산.
- 매출/순이익 성장 = 최신 공시 누적 / 전년 동기 누적 - 1 (연간은 연간끼리). 같은 기간의 자체 공시를 우선하고, 없으면 최신 공시의 검증된 전년 동기 비교열을 사용한다. 전년 기준이 0 이하이면 비교 불가. 반기 누적 등을 화면과 계산식에 표시하며 TTM 성장률로 표시하지 않는다.
- ROA = TTM 전체 순이익 / 최근 기말 전체 자산. 평균 자산이 아님을 식에 표시.
- 영업현금흐름률 = TTM OCF / TTM 매출. 설비투자/매출 = abs(TTM 유형자산 취득) / TTM 매출.
- 현금 = 최신 기말 현금및현금성자산. 기타 단기금융자산까지 포함한 유동성 총액이 아님.
- EBITDA(공시 계산) = TTM 영업이익 + 현금흐름표 감가상각·무형자산상각 조정. 합계 태그 우선, 없으면 양 구성요소 필요. 합계와 구성요소를 중복 합산하지 않음. 회사 조정 EBITDA, 영업현금흐름과 구별.
- EV = 시가총액 + 리스 포함 이자부채 + 연결 비지배지분 - 현금. 비지배지분과 부채는 장부금액; 현금 외 투자자산은 차감하지 않음. 별도 기준의 비지배지분만 0. EV/EBITDA, EV/영업이익, EV/Sales의 계산 경로를 제공.

## 의도적으로 계산을 보류하는 영역

EV 입력의 합산 검증이 우선이다. 초기에는 재무상태표에 ID 없이 정확히 `총차입금(리스부채포함)` 또는 `차입금및사채및리스부채합계`라고 공시한 단일 행만 완결된 합계로 읽는다. 이는 범용 EV 수집 완료가 아니다. 많은 실제 기업은 단기차입/유동성장기부채/사채/리스가 서로 겹치는 소계로 공시하므로 현재 `차입금·사채·리스부채 합계 자료 부족`을 표시한다. 임의의 부채총계, 모호한 차입부채 소계, 없는 행을 0으로 처리하지 않는다. 이후 주석 구조를 검증하는 수집기로 이 입력을 확장해야 한다. 삼성전자·HLB·기가비스·성호전자·KB금융 표본에서 이 제한 확인.

PEG는 예상 PER / 예상 연평균 EPS 성장률(% 숫자)을 쓰도록 정의만 노출한다. 현재 컨센서스 미연결이며 과거 순이익 성장률을 PEG로 대체하지 않는다. 사용자 예시의 PSG를 정형 지표로 임의 해석하지 않고, 요구의 핵심인 성장 고려를 매출/이익 성장률과 가격 지표를 함께 보여주는 구조로 구현한다.

FFO/AFFO, NAV/SOTP, ROIC, EV/EBITA, 배당수익률의 이 영역 통합, NIM/CET1·CSM/K-ICS, ARR/NRR·RPO, PEG 컨센서스는 추가 원천/정의 정합성 검증 후 확장 대상이다. 현재 미지원 값을 임의 생산하지 않는다. 스크리너/비교 화면의 새 지표 추가는 이 변경에 포함하지 않는다. 기존 업종 중앙값은 기존 서버 지표·동일 연결/별도 기준에만 표시한다.

## 원천과 기준

기존 FinancialFact를 읽는 Serverpod summary 계정 목록 확장. 원천 DB나 파생 지표 저장 없음, 모델 변경 없음. TTM은 연간 또는 전년 연간+현재 누적-전년 동기 누적. CF는 누적 금액. 최신 기간이 불완전하면 과거 연간으로 조용히 바꾸지 않음. 각 지표는 동일 재무 기준의 입력을 사용.
