# 최신 정기보고서 제품 추출 및 화면 점검

## 확인한 문제

아크릴의 운영 API는 2025년 사업보고서(접수번호 20260318001538)를 기준으로 제품을 표시했다. 주요 제품 표에는 조나단(GPUBase·ModelBase·AgentBase), 나디아, 에스더가 있지만 기존 규칙은 별도의 의료기기 개발 파이프라인 이름을 제품으로 선택했다. 해당 이름이 단종됐다는 판단은 하지 않았다.

프런트엔드는 회사별 정적 자산의 제품·요약·연구 설명을 API보다 우선 사용하고 있었다. 최신 정기보고서 선택도 사업보고서만 대상으로 해 반기·분기보고서를 반영하지 않았다.

## 수정한 공통 동작

- 모든 기업에 동일한 보고서 선택 SQL과 제품 추출 규칙을 적용한다. 보고서명에 적힌 실제 보고기간을 먼저 비교하고 같은 기간은 접수번호로 정정 순서를 판단한다. 늦게 접수된 과거 정정공시가 최신 반기·분기를 밀어내지 않는다.
- 최신 공시를 먼저 선택한 뒤 해당 본문을 연결한다. 최신 본문이 미수집이면 과거 제품으로 대체하지 않고 갱신 대기로 표시한다. 특정 과거 연도를 요청해도 다른 연도로 대체하지 않는다.
- 주요 제품·서비스 절의 명시적인 제품명 표를 읽는다. 제품군·세부제품·설명의 병합 행도 처리한다. 개발·임상·파이프라인·협력기관·경쟁사·자회사 표는 제외한다. 인식하지 못하는 표는 임의로 해석하지 않는다.
- 공시 제품명과 설명, 원문 행을 저장한다. 기존 제품 원리 설명을 연결할 때도 현재 제품 표의 증거가 필요하다. 규칙 버전은 40007이다.
- 회사별 정적 제품·수동 요약·연구 설명은 이 화면에서 제외했다. 기존 자산은 보존했다. 일반적인 사업 흐름은 `업종 이해`로 구분한다.
- 조회 중 AI 실행, 추출, 외부 API 호출, 쓰기는 하지 않는다. 새 본문 수집 시 저장하고 서버 시작 시 저장된 최신 본문 중 규칙 버전이 오래된 것을 다시 계산한다. DB 스키마 변경은 없다.
- 사업모델 내부 테두리와 단계별 배경 박스를 제거하고 번호·화살표·문장으로 정리했다. 기본은 접힌 상태다. 제품 선택도 테두리 없는 버튼으로 바꿨다.

## 검증과 한계

실제 아크릴 2025년 원문 스냅샷을 추출 테스트에 사용했다. 최신 반기 선택, 최신 본문 미수집, 늦은 과거 정정공시, 명시적 과거 연도, 중복 저장 방지, 지주회사·오래된 본문 차단을 저장소 통합 테스트로 검증했다. 프런트엔드 테스트는 390·1045px에서 최신 API 제품과 출처 표시 및 과거 자산 차단을 확인했다. 일반 사업모델의 320·768·1280px 레이아웃과 디자인 경계도 확인했다.

로컬 실제 브라우저에서 아크릴은 2026년 반기보고서(20260814003765)를 기준으로 표시됐다. 이 본문은 아직 없으므로 제품은 갱신 대기로 표시된다. 모든 기업의 최신 본문 수집이 완료됐다는 뜻은 아니다. 규칙이 지원하지 않는 표의 제품 추출 범위도 별도 확대가 필요하다.

화면 증거: `outputs/business-latest-2026-10-04/local-business-layout.jpg`.

운영 사이트 배포는 수행하지 않았다. 운영 데이터 스냅샷과 로컬 수정 화면을 구분해야 한다. 이번 점검 범위는 매출 성장률, 재무 지표 계약/일치성, 최신 사업보고서 선택, 제품 추출과 해당 화면이며 앱의 모든 로직을 전수 검증했다고 주장하지 않는다.

최종 결과: 변경 범위의 서버·Flutter 정적 분석 오류 없음, 서버 테스트 26개 및 Flutter 테스트 22개 통과. 자동 생성기의 중간 캐시에서 공시 API가 누락되는 문제가 발생했으나 소스의 보고서 선택 상수를 유지하고 MCP reload로 복구했으며 생성 코드 등록 테스트도 통과했다. 생성 코드는 직접 수정하지 않았다. 전체 저장소 분석에는 다른 작업의 산출물에서 기존 누락 import가 있어 변경 범위 분석을 별도로 수행했다.

Flutter Web release 빌드 통과(75.1초). 최종 서버 로그는 정상 요청을 기록했고 Flutter 로그는 생성 복구 후 reload 완료를 기록했다. 중간 생성 실패 로그는 과거 기록으로 남아 있다.
