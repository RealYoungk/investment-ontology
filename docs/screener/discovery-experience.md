# 스크리너 프리셋과 지표

2026-09-23 UX 수정: 숫자 조건은 기본으로 숨기고 `조건 직접 수정`에서 펼친다. 적용 조건 수는 항상 보이며 접어도 조건은 유지된다. 하단 계산식 문단을 제거하고 개별 필터의 탭 가능한 도움말로 이동했다. 프리셋 상세 설명도 `이 프리셋의 조건` 도움말에서 확인한다.

2026-09-22. 기존 숫자 입력 방식을 유지한다. 프리셋 선택은 숫자 조건만 교체하며 시장·정렬은 유지한다. 입력값은 수정 가능하고 URL에 보존된다. 이름은 찾으려는 기업의 특징으로 쓰고 실제 조건과 한계를 설명한다.

## 13개 프리셋

| 이름 | 채우는 값 |
| --- | --- |
| 이익 대비 저렴한 주식 | PER ≤12, ROE ≥10% |
| 돈 잘 버는 회사 | ROE ≥10%, 영업이익률 ≥10% |
| 더 팔고 더 버는 회사 | 매출·영업이익 성장률 각각 ≥10% |
| 부채 부담 낮은 배당주 | 배당수익률 ≥3%, 부채비율 ≤100% |
| 투자하고도 현금이 남는 회사 | FCF 수익률 ≥5%, 부채비율 ≤100% |
| 부채 적은 흑자 기업 | 부채비율 ≤50%, ROE ≥5% |
| 자산 대비 저렴한 주식 | PBR ≤1, PER ≤15, ROE ≥5% |
| 가격 부담 낮은 성장주 | PER ≤20, 매출·영업이익 성장률 각각 ≥10% |
| 3년 배당을 이어온 회사 | 배당수익률 ≥3%, 배당성향 ≤70%, 확인된 연속 배당 ≥3년 |
| 배당도 주고 실적도 성장 | 배당수익률 ≥2%, 배당성향 ≤60%, 확인된 연속 배당 ≥3년, 매출·영업이익 성장률 각각 ≥5% |
| 평소보다 거래가 활발한 주식 | 거래량 ≥10만주, 이전 20거래일 평균 대비 ≥2배, 평균 거래대금 ≥10억원 |
| 최근 흐름이 강한 주식 | 3개월·12개월 수익률 각각 ≥10%, 평균 거래대금 ≥10억원 |
| 연중 높은 가격대의 주식 | 52주 가격 범위 내 위치 ≥90%, 3개월 수익률 ≥10%, 평균 거래대금 ≥10억원 |

가격과 성장 / 수익성과 재무 / 배당과 현금 / 주가와 거래의 네 그룹으로 고른다. 조건은 모두 AND이며 값이 없는 기업은 해당 조건을 적용할 때 제외된다. 기준값은 수정 가능한 예시로, 성과 검증이나 업종 상대평가를 거친 투자전략이 아니다.

## 18개 숫자 입력과 결과

기존 10개 입력에 배당성향, 확인된 연속 배당 연수, 시가총액, 거래량, 평소 대비 거래량, 3개월·12개월 수익률, 52주 가격 위치를 추가했다. 단위와 도움말을 제공하며 잘못된 범위·무한값을 적용하지 않는다. 적용 중인 지표는 결과 표에도 표시하고 배당 조건에는 기준 공시연도를 함께 보여준다. 좁은 화면에서는 표를 가로로 스크롤한다.

- 배당수익률: 최신 수집 연간 공시의 현금배당 총액 / 현재 시가총액. 최신 공시가 비어 있으면 과거 양수 값으로 대체하지 않는다.
- 배당성향: 같은 공시에 보고된 연결 배당성향을 우선 사용한다. 연간 배당을 TTM 이익과 섞어 새로 계산하지 않는다.
- 연속 배당: 한 공시의 당기·전기·전전기 현금배당 총액에서 양수가 확인되는 연속 연수, 최대 3년. 과거 값이 없으면 확인 가능한 구간만 센다. 배당 증가·향후 지급을 보장하지 않는다.
- 거래량: 대표 상장증권의 최신 완료 시세일 값. 실시간 값이 아니다.
- 평소 대비 거래량: 최신 거래량 / 당일을 제외한 이전 20개 완료 거래일 평균. 20일 누락, 0인 분모, 유효하지 않은 거래량 또는 주식 수의 큰 변화가 있으면 계산하지 않는다.
- 3개월·12개월 수익률: 비교 목표일 이전 7일 이내 시세만 허용한다. 수정주가 기반 총수익률은 아니며 주식 수 변동 검사로 일부 왜곡을 제외한다.
- 52주 가격 위치: 1년 가격 이력과 유효한 비교 시세가 있는 기업의 종가 범위 기준이다. 장중 고가 돌파나 신고가 신호가 아니다.
- 성장률은 올해 누적 실적과 전년 동기간을 비교한다. 전년 이익이 0 이하인 기업을 흑자전환 후보라고 표현하지 않는다.

## 레퍼런스와 적용 범위

공식 토스증권 페이지를 기본 웹 검색과 Exa로 조사하고 브라우저에서 확인했다. 추출 본문의 시세·후보 수는 최신 검증 자료로 사용하지 않았다.

- [꾸준한 배당주](https://www.tossinvest.com/screener/8): 배당수익률과 배당성향을 함께 보는 구성 참고.
- [미래의 배당왕 찾기](https://www.tossinvest.com/screener/14): 실적과 배당을 결합하는 목적 참고. 우리 조건은 배당 증가 자체를 검증하지 않아 다른 이름을 쓴다.
- [돈 잘버는 회사 찾기](https://www.tossinvest.com/screener/10), [아직 저렴한 가치주](https://www.tossinvest.com/screener/6): 짧은 목적형 이름과 숫자 조건 연결 참고. 토스의 매출총이익률과 우리 영업이익률을 같은 지표로 취급하지 않는다.
- [주식 골라보기](https://www.tossinvest.com/screener): 실제 화면에서 연속 상승세의 1주 수익률·5일 연속 상승 조건을 확인했다. 우리 3개월·12개월 흐름 조건과 다르므로 연속 상승이라고 이름 붙이지 않는다.
- [쌍끌이 매수](https://www.tossinvest.com/screener/18): 투자자별 순매수 자료가 없어 제공하지 않는다.

토스의 정확한 임계값을 복제하지 않았다. RSI, 이동평균 돌파, 투자자별 수급, 배당 증가 이력, 사용자 프리셋 저장은 이번 구현 범위에 없다. 빈 탭이나 근거 없는 이름을 추가하지 않는다.
