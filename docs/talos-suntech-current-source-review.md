# 탈로스·썬테크 현재 원문 검토

원인원장 235 basis 중 두 회사 9 basis를 배정받아 이미 확보한 원문을 재사용했다. 추가 DART API/외부 GET/DB 실행은 하지 않았다. 전체원문 확보와 현재 BS/PL/CE/CF 검토, 정상 저장 완료는 구별한다.

## 구현한 최소 복구

탈로스 2022 OFS `20230718000182`의 직접 원문 111행을 판독했다. 표지의 법인·기간, shell의 유일한 법인코드, 원문의 URI/SHA, 제18기 현재 열과 원 단위 인쇄, CE 당기초/말을 독립적으로 결합한다. 8 핵심 금액은 실제 행에서 추출한다. BS, PL 단계별 손익, CE 변동/순손익, CF 순손익·현금 증가·입출금 합계와 BS 현금 대사를 모두 정수 원 단위로 정확히 검산한다. PPE 취득은 실제 `(217,935,190)` 유출을 보존하고 양의 취득액으로 정규화한다.

CE 당기초는 원문상 `감사받지 아니한 재무제표`다. 이것은 현재 CE 검산의 개시 증거이며 별도 과거 보고서 수치로 수집하지 않는다. 감사의견 검토/전체 계정 수집 완료를 주장하지 않는다. 숫자 Source는 기존 정상 financial worker/source cache 경로만 사용한다. 별도 보고서 복구가 연결 부재나 연결 보고서 수치로 번지지 않는다.

## 나머지 원문 상태

- 탈로스 2021·2022 CFS: 직접 `해당사항 없습니다`가 있으나 이미 exact compiled absence 등록되어 있어 중복 변경하지 않았다.
- 탈로스 2023 CFS: 제목만 있는 원문이다. 빈 내용은 작성 비적용 증명이 아니다. 미해결 유지.
- 탈로스 2021 OFS: 현재 열은 2019→2020→2021 중 마지막 열이다. 천원 인쇄의 PL 및 CE에 1천원 차이가 존재한다. `유형자산의 취득` 행은 0이지만 기계장치/비품 취득 상세는 37,841/10,784로 있다. 0을 총 취득액으로 처리하지 않았다. 독립적인 반올림·집계 범위 검증까지 미해결 유지.
- 썬테크 2022 CFS/OFS: 직접 현재 표가 있으나 CE에 2021 당기말 중복/당기초 불명확이 있어 현재기 기간 증거를 일반화하지 않았다.
- 썬테크 2023 CFS: CE 당기말 라벨이 2022로 인쇄되어 있고 CE 단위가 미인쇄다. 타 표의 단위를 무근거로 전파하지 않았다.
- 썬테크 2024 CFS: PL 순손익 -938,205,085와 CF 순손익 -1,288,353,219는 CE 비지배지분손익 -350,148,134 차이와 일치한다. 두 숫자 차이만으로 원문 오류라고 확정하지 않으며 전체/귀속 손익 범위는 추가 검증 대상이다. CE 단위 미인쇄 상태도 유지한다.

순수 실제바이트/역방향 actor·URI·SHA·기간·basis 검증 9개 통과. registry 고유성 검증 포함 10개 통과. 정적 분석 통과. DB 정상 ledger·Source·8facts·현재기간·예산0·다른basis 유지·재실행 멱등성 테스트는 작성만 했다. 다른 배포 DB 독점 종료 후 부모 에이전트가 실행할 예정이다.

## 후속: 탈로스 2021 직접 핵심7

`20221027000409` OFS 203행의 2021 우측 현재 열을 직접 검증해 현재7계정을 보완한다. 단위는 각 BS/PL/CE/CF 표에 인쇄된 천원이다. PL/CE/CF의 현재 NI는 각각268,403으로 정확 동일하며 CE 기말자본4,792,978은 BS 자본과 정확 동일하다. BS 자산12,715,300=부채7,922,322+자본4,792,978, CFO1,284,415=NI268,403+비현금769,036+운전자본246,976 및 현금 증감/개시/기말은 정확 검산된다.

인쇄 CE roll 및 PL 세부에 남는 천원 잔차(+1,+1,-1)는 고정 원문별 실제 잔차로 기록한다. 핵심 NI 불일치를 반올림으로 허용하지 않는다. 전역 rounding tolerance를 추가하지 않으며 인쇄 숫자도 수정하지 않는다. PPE 총계는 계속 미확보이고 `partialCore7`, `optionalAccountsNotCollected:['capex']`, 미확보 사유, `fullStatementCollected:false`, 세부·주석 전체미검증을 공개 source provenance에 유지한다. 0원 PPE 값은 만들지 않는다.

후속 순수9개 통과와 분석통과. 정상 DB7facts/현재기간/다른basis보존/예산0/멱등성 테스트 작성만 했다.

## 썬테크 2023 CE 인쇄 불일치의 정상 진단

자체 2023 CFS 원문에서 CE 개시3,947,377,903 + 인쇄 변동(-50,000,000,-19,038,159,+7,297,316,+8,560,627,-489,424,042)=3,404,773,645이고 인쇄 기말3,454,773,645와 raw50,000,000 차이가 있다. 자체 BS 기말 및 PL/CE/CF 순손익 자체는 일치한다. CE 통화/단위는 미인쇄이므로 raw numeric 대사로만 기록하며 CE금액의 단위를 원으로 지정하지 않는다. 다음2024 문서의 비교기간은 -50,000,000 행이 없지만 그것으로 자체2023 원문을 덮어쓰지 않는다.

exact URI/SHA/actor/basis/current-year를 만족하는 실제 원문에 한해 `KnownAnnualSourceConflict`를 반환한다. 기존 정상 worker는 failed ledger를 유지하면서 `financial-source-conflict` Source에 실제 인쇄 증거를 기록한다. noData/typedabsence/수치성공으로 전환하지 않는다. 다른 표·회사·기간·URI·SHA에는 적용하지 않는다. 기존 정상 integration 테스트 코호트에 실제 원문 fixture를 추가하여 API0·기존 반대basis Source/수치 보존·failed Source·원문SHA·재실행 유일감사 검증을 작성했다. DB 실행은 하지 않았다. 실제 정상 publicfetch와 parser 및 역방향 pure17개는 통과했다.
