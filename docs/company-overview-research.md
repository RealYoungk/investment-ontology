- 회사 소개 → 현재 투자포인트 → 제품과 용도 → 매출 구성 → 사업 지표 → 주가·소식·기업 정보.

- 기존 기업별 DB digest의 overview 첫 문단을 업종 템플릿보다 우선한다. 업종별 흐름은 ‘사업모델 이해하기’ 안에서만 보여주며, 업종 공통 성장 요인을 기업의 투자포인트로 표시하지 않는다.
- 수주잔고·가동률·점유율·생산·투자 지표는 검증된 DB factTrends를 사용한다. 매출 구성 및 연구개발비의 중복 표를 추가하지 않는다. 단위와 투자계획/집행을 분리한다.
- 별도 사업의 내용 탭을 메뉴에서 제거한다. 기존 ?tab=business 주소는 개요로 열리며, 사업 원문은 개요의 선택적 팝업/바텀시트에서 연도·소제목으로 읽는다.

## 연구 입력과 갱신

파일 기반 CompanyResearchProfile에 설명·제품·사업 부문·투자포인트와 함께 아래 항목을 보관한다. 자료를 작성할 때는 원문 본문을 읽고 검증해야 하며 검색 결과 요약만으로 작성하지 않는다.

1. 최신 연간 사업보고서: 제품·고객·수익 구조, 사업별 규모를 확인한다.
2. 이후 가장 최근 분기/반기보고서: 신규 사업, 제품 출시, 계약, 사업 구조의 변경을 확인한다. 변경이 없더라도 검토한 보고서의 기간과 접수번호를 기록한다.
3. 보고서 이후의 회사 IR·공시: 양산과 샘플, 계획과 실적을 구분하고 중요한 변화만 반영한다.
4. sources에 URL·기간·본문 근거를, coveredYear/coveredPeriod/coveredReceipt에 검토 범위를, checkedAt에 확인일을 기록한다. 숫자는 별도 설명에 복제하지 않고 기존 API/DB 화면을 사용한다.
5. 금융 summary에서 더 새로운 기간 또는 같은 기간의 다른 접수번호가 확인되면 기존 ‘현재 투자포인트’를 표시하지 않는다. 사업 구조 설명은 유지한다. 이 비교는 현재 수집된 재무 보고서 범위이며, 미수집 공시를 탐지하는 전수 감시는 아니다.
