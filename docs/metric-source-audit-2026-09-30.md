## 발견·수정

1. **외화가 원화처럼 표시되던 문제:** FinancialLine에 currency를 전달. 같은 통화의 ROE·이익률은 유지하고, 통화가 다른 분자·분모 및 TTM 기간은 계산하지 않는다. 현금·EBITDA·상세 입력·재무 차트는 원래 통화로 표시한다. 스크리너 역시 외화를 원화 시총과 나누지 않는다.
2. **대체 표준 ID 누락:** IFRS 영업이익과 고객계약매출의 표준 계정을 추가하고 서버 SQL·Dart의 우선순위를 일치시켰다. 상품·서비스 일부 매출 계정을 총매출로 대체하지 않는다.
3. **전각 공백:** Unicode 공백을 동일하게 정규화해 원천에 있는 취득액이 서버 SQL과 Dart에서 달리 선택되지 않도록 했다.
4. **자산·부채·자본 모순:** 원천 금액을 보존하면서 계산 불가 사유를 DTO로 전달. 허용 오차는 max(1,000 표시 통화 단위, 자산의 1ppm). 이를 넘는 47개 보고서의 관련 재무상태표 파생값은 계산 차단한다. 최신 기준 3개 연결/별도 묶음에서 해당 조건을 확인했다.
5. **웹 release의 nullable BigInt 복사:** 생성 모델의 `copyWith(amount: null)`가 웹 최적화 빌드에서 원래 값을 유지하는 현상을 컴파일 결과와 공개 화면에서 확인했다. 오류 입력은 새 DTO를 명시적으로 구성하여 금액을 제외한다. 사조동아원 공개 화면과 PER 상세에서 구체적 합계 불일치 사유를 확인했고, 회귀 테스트와 전수 사유 대조를 추가했다.
6. **통화가 바뀐 과거 기간:** 서로 다른 통화의 연간·누적 금액을 합산하지 않는다. 재무 추이도 동일 통화 구간이라는 전제 없이 연결하지 않는다.

선택된 원천 금액을 임의 수정하거나 환율·누락 차입금·예상 EPS를 추정 입력하지 않았다. 계산 대상에 필요한 원천이 없으면 기존 기간·항목 사유를 유지한다.
