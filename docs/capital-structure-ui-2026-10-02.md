# 주식 수와 잠재 희석 화면

2026-10-02 사용자 요청: 발행주식에 더해 발행 가능한 주식 수, CB/BW/EB 오버행과 본인 지분 희석을 확인하고 불필요한 접힘을 줄인다.

## 구현 범위

- 기존 stockTotqySttus 응답의 isu_stock_totqy를 StockTotalRow.authorized로 전달한다. DTO만 확장하며 DB 테이블/마이그레이션 변경은 없다.
- 주주환원 주식 수 표를 항상 표시하고 발행 가능한 총수 열을 추가했다.
- 지배구조에 주식 종류별 발행주식·정관상 한도·자기주식과 수량 입력형 희석 계산을 표시한다.
- 지분율 = 보유주식 / (발행주식 + 추가 신주). 기존 지분의 상대 감소율 = 추가 신주 / (발행주식 + 추가 신주). EB 기존 주식 교환은 추가 신주에 포함하지 않는다.
- 기존 저장된 자금조달 주요사항보고서 조회 UI를 지배구조에 연결했다. 화면 진입으로 외부 API 수집이나 유료 호출을 하지 않는다.
- 관계망·경영진·출자 및 역방향 관계를 열린 카드로 표시한다. 주주 수량 원천 상세와 소량 보유 관계인 상세는 접힘을 유지했다.

## 잔여물량 구현 완료

최신 정기보고서의 회사 식별·보고기간을 확인하고, CB/BW/EB 미상환 표를 규칙으로 추출한다. 회차별 잔액·원문 단위·전환가·가능 주식 수·행사기간·행 근거와 원문 SHA256을 기존 ResearchSnapshot/Source에 보존한다. 저장된 결과만 공개 조회하며, 명시적 수집은 관리자 권한을 요구한다. 기존 원문 ZIP 수집에도 연결했다. DB 마이그레이션 없음.

공시 주식 수를 잔액 × 단위 × 비율 ÷ 가격으로 검산한다. 불일치는 삭제하거나 수정하지 않고 표시한다. 미확보와 공시상 해당 없음을 구별한다. 최신 보고서가 생기면 과거 잔여물량을 현재 값으로 사용하지 않는다. 같은 기준일 주식 총수가 확보된 경우에만 검산 통과한 같은 주식 종류 CB/BW 수량을 계산기로 전달한다. EB는 신주 희석에서 제외한다.

잔여물량은 보고서 기준 스냅샷이다. 기준일 이후 전환·상환·리픽싱, 분리형 BW 잔존 권리 등 표에 없는 사항을 완전하게 추적했다고 주장하지 않는다. 기존 기업들의 자본 자료 일괄 백필/운영 배포는 실행하지 않았다. 미수집 기업은 미확보 상태를 표시하며 관리자가 원문 수집할 수 있다.

타법인 출자 표는 처음 20개를 노출하고 20개씩 더 보는 방식으로 바꿔 긴 페이지를 줄였다.
