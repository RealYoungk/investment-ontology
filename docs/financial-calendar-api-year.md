# 재무 조회연도와 회계연도

재무 원장의 `bsnsYear`는 결산 종료 회계연도다. OpenDART 요청 `bsns_year`는 보고서 이름에 적힌 실제 기간 종료 연도(`DartReportName.periodYear`)를 쓴다. 예를 들어 3월 결산 기업의 2026년 6월 분기는 원장 FY2027, API 요청2026이다. 보고서 코드 판정과 과거 5개 회계연도 범위는 바꾸지 않는다.

공식 공개 조회 화면은 보고기간 종료일의 연도를 사용한다고 명시한다. 에스브이인베스트먼트와 테라뷰의 공개 조회2026은 각각20260813001312/20260923000617 최신접수번호를 반환하고,2027은 결과가 없다. 동일접수 XBRL 및 인쇄 재무제표에서 실제 기간과 금액을 확인했다.

최신 수집범위의 기존 양쪽 noData 중 조회연도가 회계연도와 달랐던 중간보고서만 한 번 재시도한다. 재시도 표식을 장부에 남겨 실제013을 반복해서 열지 않는다. 평상시 재무 일일예산은18,000이며, 이 조회연도 보완만 최대40호출을 공통20,000호출 잔액 안에서 허용한다. 매 연결/별도 요청 전에 피드를 포함한 사용량을 flush하고 공통잔액을 재확인한다. 과거 중간보고서나 다른 API noData는 확대·초기화하지 않는다.

응답 접수번호는 요청한 공시 또는 원장에서 회사·실제기간·회계연도·보고서코드가 일치한 공시여야 한다. 동일접수로 잘못 저장된 회계연도는 새 원천 응답과 기존 수치·통화가 전부 일치할 때만 감사기록과 함께 메타데이터를 복구한다. 원래 수치와 출처는 보존한다. 검증이 실패하면 별도 복구가 필요한 실패로 남긴다.

정기보고서 주요정보28종에도 같은 연도해석 위험이 있지만 이번 사용자 수집 범위에서 제외되어 변경하지 않았다. KONEX 다수 noData는 XBRL 제공대상/원본부재 가능성을 별도로 확인해야 한다. API noData를 재무자료 저장 성공으로 취급하지 않는다.

공식근거: [단일회사 재무제표 공개조회](https://opendart.fss.or.kr/disclosureinfo/fnltt/singl/main.do), [전체 재무제표 API 개발가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020). 이 조사에서는 인증키를 취득하지 않았으며 공개조회 결과와 동일접수 XBRL을 대조했다. 실제 API 응답은 정상 수집 경로에서 접수번호·연도를 다시 검증한다.
