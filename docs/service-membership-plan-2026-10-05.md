# 서비스 소개와 단일 멤버십 기획

2026-10-05 사용자 인터뷰 결과. 사용자 결정과 구현 제안을 구분한다.

## 확정한 방향

- 고객: 이미 적극적으로 투자하는 투자자.
- 서비스: 종목발굴 → 기업분석 → 모니터링. 어느 한 축을 최종 목표에서 제외하지 않는다.
- 가치: 정밀한 숫자, 논리와 근거, 먼저 정리되어 있는 분석, 능동적 변화 추적, 작성자가 선별한 투자 기회.
- 무료: 관심종목 소개와 기업분석 기능을 충분히 경험할 수 있게 한다.
- 유료: 탑픽·상세 투자 관점·관심기업 모니터링 한도 확대를 하나의 멤버십에 포함한다. 등급별 추가 요금제는 만들지 않는다.
- 관심종목·탑픽의 선정과 뷰는 사용자가 결정한다.
- 채팅에서 AI와 콘텐츠를 작성하고 사용자 최종 확인 후 공개한다. 별도 편집 화면은 필요하지 않다.
- 투자 관점 변화는 날짜별 후속 글로 남긴다.
- 첫 콘텐츠 후보는 아크릴. 사용자가 주목한 중심은 GPU 운영 소프트웨어의 네트워크 기술 차별성이다. 관심종목/탑픽 등급 자체는 아직 지정하지 않았다.

## 현재 코드와의 차이

| 영역 | 현재 구현 | 추가할 범위 |
| --- | --- | --- |
| 기업분석 | 기업·재무·스크리너·기업 비교·출처 | 기존 공개 분석 유지 |
| 멤버십 | 기본 월 4,900원, 신규 가격 4,900/9,900/14,900/19,900 설정; 구독 유지 시 가입 가격 보호 | 새 요금제 없이 콘텐츠 접근 권한 포함 |
| 관심기업 | 무료 3개 / 멤버십 20개 | 기존 서버 한도와 원장 재사용 |
| 모니터링 | 공시 알림함·Web Push | 뉴스·매출·수주 변화, 필요할 때 투자 관점 해석 |
| 작성자 콘텐츠 | 이번 작업에서 발행 기반·무료 소개·회원 본문·후속 글 구현 | 첫 글 작성자 승인 후 공개 |

가격은 코드 기본값이며 현재 운영 가격을 조회한 결과가 아니다. 미래 콘텐츠는 현재 결제 혜택으로 표시하지 않는다. 기존 자동 추출 중단 정책을 이 인터뷰만으로 전 기업 AI 배치 허용으로 해석하지 않는다. 이번에 허용한 아크릴 초안과 작성자 콘텐츠만 범위로 삼는다.

## 소개 문구

발견하고, 분석하고, 변화를 놓치지 않도록.

어떤 기업을 볼지부터, 무엇을 확인할지까지. 기업의 사업과 숫자를 살펴보고, 관심기업의 변화를 이어서 확인하세요.

분석 도구의 실제 기능을 먼저 설명하고 현재 멤버십과 준비 중인 작성자 콘텐츠를 구분한다. 수익을 보장하지 않는다. 사용자 관점의 공개와 독자의 판단을 구분한다.

## 개발 제안과 완료 기준

1. 소개: 세 축, 무료 경험, 단일 멤버십 방향과 현재 제공 범위. `/about`에 구현하고 기존 탐색·영상 fallback·모바일 배치를 검증한다.
2. 발행 기반: Serverpod가 초안·공개 상태, 기업 연결, 공개 범위, 작성자, 출처, 승인·발행 시각, 후속 글 연결을 관리한다. 로컬 파일 작성 → admin 전용 검증/import → 미리보기 → 사용자 승인 뒤 publish. 승인되지 않은 아크릴 초안을 공개하지 않는다.
3. 조회: 무료 소개와 유료 본문을 서버에서 구분한다. 초안은 admin만 조회한다. 유료 본문은 활성 이용권 확인 후 반환하며 무료 응답·검색·HTML에 포함하지 않는다. UI에서만 숨기는 paywall은 사용하지 않는다.
4. 독자 경험: 기업 상세의 투자 관점과 날짜별 후속 기록, 발굴 목록에 공개 콘텐츠 연결. 준비된 콘텐츠가 없는 기업에는 빈 상태를 표시한다. 새로운 편집 화면은 만들지 않는다.
5. 모니터링: 기존 공시 알림을 보존하며, 뉴스·사업 수치는 원천·중복·회사 식별·실패 상태를 검증한 뒤 확장한다. 모든 변화를 해석한다는 약속 대신, 중요한 변화의 해석을 출처 및 작성자 관점과 연결한다.

검증: 익명/무료/활성회원/만료회원/admin의 콘텐츠 조회 권한, 초안 비공개, 후속 글의 원글 유지, 원천 연결, 3/20개 한도 및 모바일 탐색. 실제 발행은 사용자 최종 확인 후 수행한다.

## 남은 사실 확인

- 현재 법적·운영 준비 상태와 공개 문구의 일치 여부. 사용자는 유사투자자문업 교육에 갈 계획이라고 말했다. 교육 이수나 신고 완료로 기록하지 않는다.
- 아크릴 탑픽 등급, 최신 가격·밸류에이션·수익화 구조·상용 계약은 아직 검증하지 않았다.
- 뉴스 및 숫자 변화 알림은 현재 완성된 기능으로 소개하지 않는다.

## 이번 작업 결과 (개발 후 갱신)

- 소개를 종목발굴·기업분석·모니터링으로 수정하고, 홈·검색·상단 메뉴에 `/insights` 투자 관점 진입점을 연결했다. 기업 개요에서도 해당 기업의 글과 후속 기록으로 이동한다.
- Serverpod `investmentNotes` endpoint는 기존 ResearchArticle/ResearchRevision을 재사용한다. 신규 모델·마이그레이션은 없다. 관리자 전용 초안 import/preview, 정확한 초안·버전에 대한 승인 digest 확인 후 publish를 제공한다. 공개된 원글은 수정할 수 없으며 같은 기업의 후속 글로 관점 변화를 기록한다.
- 공개 목록·상세는 활성 멤버십 원장을 서버에서 확인한다. 무료 관심종목 소개만 반환하며 회원 본문·출처는 무료 응답에서 제외한다. 무료 탑픽은 기업 식별과 상세 소개까지 제외한다. 초안은 관리자만 조회한다. 로그아웃 시 화면의 회원 본문과 오래된 응답을 폐기한다.
- 발행 시 기존 관심기업 알림함·Web Push 전달 큐에 업데이트를 기록한다. 알림 제목은 상세 투자 내용을 노출하지 않는다. 앱에서는 공시와 투자 관점을 구분하고 투자 관점 알림은 앱 내부 글로 이동한다. 실제 외부 Push 배송은 발행·기기 구독이 없어 미검증이다.
- 작성은 `tool/investment_notes/manage.py`의 import → preview → publish 순서로 진행한다. 관리자 로그인 토큰이 필요하며 import는 발행하지 않는다. 별도 편집 화면은 추가하지 않았다. 미리보기는 `/insights/<id>?preview=true`이다.
- 프런트엔드 lib 전체 및 서버 변경 소스/테스트 정적 분석 이상 없음. 관련 Flutter 테스트 34개, 서버 단위·격리 DB·생성 등록 테스트 9개 통과. Python CLI 문법 검증 통과. 기존 3/20개 한도와 결제 개시 조건은 유지하며 이번에 결제망 실거래를 수행하지 않았다.
- 실제 Flutter 앱 컴파일·hot restart 성공, Driver health 정상. 브라우저 공개 목록과 390px 모바일 화면의 빈 상태·탐색 CTA를 확인했고 당시 브라우저 경고/오류는 없었다. DTD Driver의 특정 텍스트 조회는 timeout이므로 자동 Driver 탐색 전체 성공으로 기록하지 않는다. 회원/만료/관리자 시나리오는 격리 DB와 widget test에서 검증했다.
- 아크릴 원문 조사 기록은 `docs/acryl-network-research-draft-2026-10-05.md`, 발행용 구조 초안은 `outputs/investment-notes/acryl-draft.json`이다. 초안의 watchlist 값은 제안일 뿐 사용자 선정 확정이 아니다. 운영 DB에 import하거나 공개하지 않았다.
- 뉴스·매출·수주 자동 알림 확장, 첫 콘텐츠 최종 확인 및 발행, 운영 배포는 남아 있다. 이번 결과는 단일 멤버십의 작성자 콘텐츠 기반과 서비스 소개의 로컬 구현·검증이다.

## 서비스 소개 화면 최종 반영

추가 요청에 따라 `/about`에 무료/단일 멤버십 비교 영역을 구현했다. 무료 분석·관심종목 소개·3개 모니터링과 탑픽·상세 근거·후속 기록·20개 모니터링을 직접 비교하며 넓은 화면은 2열, 좁은 화면은 세로 배치한다. 세 축의 설명에 작성자 관점을 연결하고 투자 관점 및 멤버십으로 이동하는 버튼을 제공한다. 콘텐츠 공개 준비와 뉴스/수주/매출 자동 알림 준비 상태를 명시했다. Flutter 홈·소개·디자인 경계 20개 테스트 및 정적 분석 통과, 실제 데스크톱/좁은 브라우저 화면과 멤버십 버튼 이동 확인. 운영 배포는 별도다.

## 소개 영상 제거와 코드 모션

사용자 요청으로 MP4 다운로드·영상 DOM·준비/실패 미리보기를 제거하고 Flutter IntroMotionSurface로 교체했다. 공시·실적·사업·고객·공급·경쟁 정보가 스크롤 위치에 따라 기업 중심으로 모인 뒤 관계망으로 연결된다. 별도 미디어·이미지 요청과 재생 타이머가 없으며 움직임 줄이기는 정적인 최종 연결 상태를 보여준다. 원래의 페이지 단일 스크롤과 3개 장면 제목을 유지한다. 사용하지 않는 MP4/포스터 자산도 제거했다. 관련 Flutter 25개 테스트, 변경 소스 정적 분석, 웹 빌드 통과. 개발 서버의 web/app에 폰 확인용 빌드를 갱신했으며 운영 배포는 아니다.

코드 모션의 추가 연출: 아이콘·그라데이션·그림자 정보 카드, 중심의 동심 궤도와 회전 호, 단계별 곡선 연결선, 연결선을 따라 움직이는 빛과 잔상을 추가했다. 모든 움직임은 스크롤 진행값에 연결되어 별도 타이머나 영상 요청을 사용하지 않는다. 모바일은 카드의 보조 장식을 줄인다. 관련 6개 검사와 정적 분석·웹 빌드 통과.

스크롤 속도 피드백 반영: 전체 페이지 스크롤 길이·입력 처리는 유지하고 진행률의 처음 14%, 중간 40~60%, 마지막 84~100%에 장면 유지 구간을 넣었다. 그래픽은 320ms ease-out으로 목표 진행률을 따라오며 움직임 줄이기는 즉시 정적 최종 상태다. 장면 유지·단조 진행 및 기존 동작 테스트 4개, 정적 분석, 웹 빌드 통과. 폰 확인용 web/app 빌드를 갱신했다.

## 멤버십 프리미엄 강조와 진입 문구

사용자 요청으로 소개의 멤버십 카드 및 멤버십 혜택 카드에 네이비 그라데이션, 샴페인 골드 포인트·버튼, 전용 멤버십 레이블을 적용했다. 팔레트와 패널 장식은 design/premium_style.dart에 둔다. 소개의 공개/자동 알림 준비 안내는 투자 관점과 관심기업 화면으로 이어지는 리서치 진입 영역으로 교체했다. 미제공 자동 뉴스/매출/수주 알림을 제공한다고 주장하지 않는다. 혜택 화면의 결제 가능 여부와 현재 요금·갱신·해지 조건은 기존 처리를 유지한다. 홈·소개/멤버십/디자인 경계 테스트 25개 통과.
