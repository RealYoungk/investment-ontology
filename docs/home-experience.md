# 홈과 소개 페이지 — 2026-09-22

## 해결하려는 문제

사용자 보고: 투자 초보자는 서비스의 목적과 사용법을 알기 어렵고, 중간 경험자는 첫 화면의 많은 데이터와 긴 텍스트 때문에 읽는 순서를 잡기 어렵다.

이번 구현은 첫 방문부터 기업 하나를 살펴보는 흐름에 집중한다. 다른 세션에서 진행하는 전반적인 스타일 작업과 맞물리도록 기존 디자인 토큰을 사용한다. 사용성 개선 효과는 아직 사용자 E2E로 검증하지 않았다.

## 구현

- `/`, 기본 시작 → `/home`. 홈은 기업 검색, 예시 검색, 목적 선택을 제공한다. 최초 검색 전 API 조회를 하지 않는다.
- 기업 이해 → 기업 개요, 실적 확인 → 재무 탭, 기업 비교 → 선택 기업을 넣은 비교 화면. 기존 상세 데이터와 계산식을 재사용한다.
- `/about`은 별도 소개 화면. 세 가지 질문을 눌러 사용법을 살펴보고 선택한 목적을 `/home?intent=`로 전달한다. FAQ는 펼칠 때 읽는다.
- 검색은 250ms 지연, 최대 6개 결과. 늦은 응답 무시, 지우기, 재시도, 결과 없음, 전체 결과 이동을 제공한다. Enter는 검색을 실행하며 임의로 첫 기업을 선택하지 않는다.
- 예시는 실제 기업 검색이다. 가짜 데이터·수익률·고객 수·투자 추천을 표시하지 않는다.
- 기업 개요는 사업 → 실적 → 사업 주요정보 → 주가 순서. 사업 설명은 네 줄을 먼저 보여주고 전체 내용을 펼칠 수 있다. 대표자·주소·연락처는 접어 둔다.
- 전반적인 브랜드·데이터 수집·백엔드·생성 코드는 변경하지 않았다.

## 확인한 사항

- `dart analyze`: 이상 없음.
- 홈 관련 위젯 10개 + 라우팅 1개 + 디자인 경계 2개, 총 13개 테스트 통과.
- 320/768/1440px, 글자 배율 1.3에서 홈·소개 레이아웃 오류 없음.
- 지연 응답 역전, 검색 실패/재시도/빈 결과, 세 목적별 목적지, 뒤로가기 검색 유지, 소개에서 목적 전달 확인.
- 실제 브라우저: 홈 렌더링, 삼성전자 실검색 → 기업 개요 → 뒤로가기, 소개 → 실적 확인 → 해당 목적 홈 연결 확인.
- Flutter Driver는 연결되었으나 탭 조작/스크린샷이 안정적으로 동작하지 않아 실제 화면 확인은 Codex 브라우저로 수행.

## 사용자 E2E

1. 소개를 읽지 않고 홈을 열어 서비스가 무엇을 해주는지 설명할 수 있는가?
2. 도움 없이 기업을 찾아서 무엇을 하는 회사인지 확인할 수 있는가?
3. 실적 확인과 기업 비교 목적을 선택했을 때 예상한 화면으로 이동하는가?
4. 긴 글은 필요할 때 읽을 수 있고, 첫 화면에서 읽을 순서가 보이는가?
5. 소개 페이지를 읽은 후 실제로 해보고 싶은 행동이 생기는가?
