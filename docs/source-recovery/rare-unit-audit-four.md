# 직접 인쇄 단위가 있는 감사 원천 4개

이 후보는 원문 재무표 자체에 원 단위가 인쇄된 별도 감사 재무제표를 사용한다. 주변 표의 단위를 빌리지 않는다. 회사·접수·연간 기간·별도 기준·현재 열·직접 핵심 7계정·자산 등식·자본변동표의 전체 순손익과 기말 자본을 검증한다. 원문 URI와 바이트 SHA는 고정 패키지에 보존한다.

마지막 대상은 공식 정정본 선택 메뉴의 원접수 감사 첨부 관계를 별도로 검증한다. 실제 FinancialReport/Source 식별자는 20250317000704이며 대상 접수로 덮어쓰지 않는다. 정정 선택 메뉴, 원접수 메뉴, 원표지, 감사 메뉴, 전체 감사 본문 총 5개의 원자료를 고정한다. 나머지는 표지·공시 메뉴·감사 메뉴·본문 4개를 고정한다.

미래에셋벤처투자 2021 원문 `III.. 영업이익`은 그 정확한 감사 원문에서만 핵심 영업이익으로 읽는다. 저장 계정명은 원문을 그대로 유지하며 Dart/SQL 핵심 분류도 같은 정확 명칭을 사용한다.

썬테크 2023 CFS는 이번 복구에서 제외한다. 감사 자본변동표의 `2023.12.31(당기초)`가 표지의 2023.01.01 시작일과 충돌한다. 숫자가 존재해도 날짜를 고치거나 별도 자료로 대체하지 않는다.

증거는 `outputs/filing-collection-priority/rare-unit-four-readonly-20261003/audit-ledger.json`에 있다. 감사 메뉴 5건·본문 5건·2024 원접수 메뉴/표지 2건, 공식 공개 GET 총 12건으로 직접 확인했다. 전체 주석을 검증했다는 의미가 아니며 표지·회사·단위·현재 핵심 표·자본변동표의 검토 범위다.

정상 큐와 불변 캐시는 기존 공용 저장 트랜잭션을 사용한다. 기존 반대 기준 자료를 보존하며 한 번 감사, 합계 최대 10건, 실패 회로 6건, 공개 시도 3회와 API 예산은 그대로다. 격리 DB의 반대 기준 보존 자료는 합성 sentinel이며 운영 DB 전체 원형 검증으로 주장하지 않는다.

검증: 단위 원문 양성/변조·회사/기간/기준/URI/단위 음성, 정상 공개 시도 2→3 및 불변 캐시 시도3 각 4건의 정상 큐 저장·출처·요약·SQL·재실행 회귀를 수행한다. 실행 결과는 최종 커밋 보고에 명시한다.

최종 focused 검증: 신규 단위 30 PASS, 정상 큐/캐시 DB8 PASS 및 teardown 종료, 소유 11파일 analyze0/format변경0. 공용 registry의 linked rule 고정 바이트 읽기 수(manifest+5raw)와 실제 원접수 기대를 보완한 focused 1 PASS. 전체 registry 재실행은 별도 진행 중이며 전체 PASS로 주장하지 않는다.
