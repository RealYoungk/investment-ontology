# 메디쎄이 당기 CF 표제 후보

대상은 법인코드 01018617, 접수번호 20260327001807, FY2025 연결 재무제표뿐이다. 원문 CF 당기 열 `제 23당) 기말`을 원문 수정 없이 인식한다. 제23기, 표지의 2025-01-01~2025-12-31, 고정 공식 URI 좌표, 당기·전기·전전기 열 위치, 원 단위, 필수 핵심계정 7개와 BS 등식은 유지한다. CE의 고유한 당기초·당기말과 직접 전체 순손익/기말자본을 CIS/BS와 대조한다. 일반 괄호 복구는 적용하지 않는다.

불변 원문 패키지는 공식 shell/cover/CFS 3개를 byte 그대로 저장하고 manifest SHA로 검증한다. 기존 한 번 성공·실패 감사와 정상 저장 경로를 재사용한다. 합계 10개/연속 실패 6개/공개 시도 3회 한도와 취소·최종 정정 선택은 변경하지 않는다. 정확한 CFS 우선순위만 추가했다.

직접 전체 당기 값은 자산 45,102,016,879원, 부채 7,405,512,610원, 자본 37,696,504,269원, 매출 28,309,005,387원, 영업이익 3,953,011,720원, 순손익 3,328,325,280원, 영업현금흐름 3,457,919,863원이다. 원문 유형자산 취득 행은 보존하지만 이번 후보는 그 표기 확장 없이 필수 7개만 검증한다.

실제 원문 및 음성 단위 22개, 불변 캐시 단위 14개 통과. DB 정상 큐/Source/summary 검증은 루트의 독점 슬롯 승인 후 별도로 진행한다. 운영 쓰기, 추가 GET/API, 카운터 초기화, 모델·생성 코드 변경은 없다.

후속 격리 DB2 통과: 공개 시도 2→3 정상 transport 큐에서 실제 7개 저장과 Source 공식 URI/원접수/행 provenance, 매출 summary, 반대 basis 합성 보존 sentinel의 Source/report/fact 전체 JSON 불변을 확인했다. 시도 3회 불변 캐시의 실제 저장 및 재실행 중복 방지도 기존 registry 정상job 회귀에서 확인했다. API 호출 0, 일반 attempt 및 일일 API 원장 값 불변. 반대 basis는 합성 sentinel 검증이며 운영 비공개 DB 반출 검증이 아니다. 첫 실행의 테스트 provenance 키 오기는 실제 계약 `source`로 수정해 동일 공식 URI 대조를 유지했다.
