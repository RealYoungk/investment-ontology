# 상단 지표 전수 검증 — 2026-09-30

## 범위와 결과

로컬 운영 API의 상장사 목록 2,756개 및 각 기업의 자동 선택 재무 기준 응답을 읽었다. 요청 오류 0건. 같은 응답에 실제 Flutter FinancialView/MetricProfile을 실행했다. 23개 지표 × 2,756개 기업 = 63,388개 결과에서 값은 유한수이거나 구체적인 누락 사유를 가진다. 추천 지표는 기업당 6개다.

이 검증은 계산·표시 계약 검사이며, 모든 원문 숫자를 수작업 대조하거나 모든 기업의 연결/별도 선택을 각각 화면 검수했다는 뜻은 아니다.

## 수정

- ID 없는 정확한 매출액·현금및현금성자산·감가상각비·무형자산상각비를 해당 재무제표의 유일한 후보일 때 보완. 기존 표준 ID 우선, 세부 내역 제외, 정정 전 행 제외. 제품별 매출·현금 증감·사용권자산 상각만 있는 행을 총계로 쓰지 않는다.
- TTM 누락 이유에 기간과 계정명을 함께 표시. 보고서 자체가 없으면 재무 자료 없음으로 표시.
- 시가총액 0 이하를 배수 계산에 사용하지 않는다.
- 취득액 부호가 보고서마다 다른 76개 기업 확인. TTM 투자액을 각 공시 취득액의 절댓값으로 계산한 후 합산·차감하도록 변경. 이전에는 합산 후 절댓값이어서 왜곡될 수 있었다. 서버 공통 SQL과 화면 계산에 동일 적용.
- 정규화 후에도 TTM 취득액이 음수인 11개 기업은 FCF를 계산하지 않고 기간별 금액 불일치로 표시. 누락을 0으로 추정하지 않는다.

## 미해결 범위

- EV 3종은 이자부채 총계 확보 범위가 없어 현재 전 기업 미계산. 금융부채 세부 항목을 임의 합산해 총계로 간주하지 않았다.
- 예상 PEG는 컨센서스 입력 미연결.
- 기타 공시 계정 변형, 금액 단위, 보고기간 변경, 정정으로 인한 비교 불일치를 모든 원문에 대해 보증하지 않는다.
- 과거 원문에 값이 있는데 API/추출 단계에서 누락된 모든 사례의 해결을 의미하지 않는다. 임의 보완보다 추가 원천 검증이 필요하다.
