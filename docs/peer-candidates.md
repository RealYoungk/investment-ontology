# 공시 제품군 기반 비교 후보

특정 기업별 수동 명단 대신, 최신 공시의 주요 제품 표를 동일한 규칙으로 전처리한다. 기업 비교에서는 첫 기업의 제품을 선택하면 해당 제품을 공유하는 후보를 최대 5개 제공한다. 후보를 누르면 최대 4개 기업까지 추가한다. 경쟁사 확정이나 투자 추천이 아니다.

## 선정 규칙

- `product_taxonomy.dart`는 메모리·기판·배터리·식품·타이어·화장품·화학·전력기기 등 구체적인 제품의 동의어를 정규화한다. 미등록 제품은 엄격한 필터를 통과한 제품명 완전 일치만 허용한다. 기업명별 예외 명단은 없다.
- 제품은 주요 제품 절의 명시적인 제품 열에서만 읽는다. 사용처·가격·연구개발·경쟁사·합계·일반적인 서비스는 제품으로 사용하지 않는다. 병합 행의 열 위치가 모호하면 건너뛴다. 금액과 비중의 결합 셀은 수치 형식을 확인한 경우만 허용한다.
- 일반 제품은 동일 제품과 KSIC 앞 두 자리가 모두 같아야 한다. 이는 다른 공급망 역할을 줄이는 보조 필터이며 사업모델 동일성을 보증하지 않는다.
- 검사장비는 검사 대상과 방식이 모두 겹쳐야 한다. 기판·Flip-chip은 인접 제품군 묶음이며 같은 세부 공정이나 직접 경쟁을 뜻하지 않는다. 방식만 겹치는 장비로 빈자리를 채우지 않는다.
- 후보는 선택한 제품을 반드시 공유한다. 기본 제품은 검사 대상, 사전 정의 제품, 기타 정확 일치 제품 순서다. **기본 선택은 최대 매출 사업이라는 뜻이 아니다.** 여러 사업을 가진 기업은 제품을 바꿔 비교한다.
- 시가총액·PER 유사성은 사업 유사성의 근거로 쓰지 않는다. 공통 제품 수와 다른 제품 수를 이용해 순위를 정하고 안정적인 동률 순서를 적용한다.

## 전처리와 상태

`peer_profile`에 문서 ID, 규칙 버전, 제품 신호, 원문 인용을 저장한다. 신규 본문 수집과 서버 시작 시 미처리 최신 문서를 전처리한다. 빈 결과도 처리 완료로 저장한다. 조회 중 AI 호출이나 본문 분석은 없다.

최신 활성 문서와 현재 규칙 버전이 일치하는 프로필만 사용한다. 최근 3개 회계연도 밖의 공시, 지주사, 미상장사는 제외한다. 최신 문서가 미처리라고 과거 후보를 대신 보여주지 않는다. 원문 없음·처리 중·제품 미확인·해당 제품 후보 없음은 구분한다. 수동 검색은 계속 제공한다.

## 화면의 정보 순서

기본 화면에는 회사명, 공통 제품 한 문장, 추가 버튼만 둔다. ‘비교 이유 보기’를 열면 공통 사업을 큰 글씨로 먼저 보여주고, 회사별 다른 제품을 나누어 읽게 한다. 공시 연도·원문·출처 링크는 그 안의 ‘공시 근거 보기’에 접어 둔다. 카드와 대화상자는 모바일에서 한 열로 표시한다.

제품 일치는 매출 구성·고객·수익구조 일치 검증이 아니다. 차이 영역에서 이를 짧게 알린다. 추출 누락은 사업 부재를 뜻하지 않는다. 사람/AI의 자유 서술을 자동 사실로 주입하지 않는다.

## 확장과 검증

1. 제품 사전 또는 표 파서를 확장할 때 실제 공시 형태를 재현한 양성·음성 테스트를 추가한다. 제품 제조사와 해당 제품용 장비·원료 업체가 섞이지 않는지 확인한다.
2. `PeerRules.version`을 올린다. 서버의 자동 생성/재시작 후 최신 문서가 새 버전으로 재처리된다. 생성 코드를 직접 수정하지 않는다.
3. `tool/peers/export.sql`에 현재 `rule_version`을 주어 읽기 전용 스냅샷을 만든다. `dart run tool/peers/audit.dart snapshot.json report.json`으로 제품 분포와 기본 제품 기준 후보를 확인한다. 상세 명령은 해당 폴더 README 참조.
4. 규칙/DB/API 등록 테스트, Flutter 상태/가독성 테스트와 실제 제품 전환·근거 펼치기·모바일 화면을 확인한다.

### 2026-09-28 규칙 v7 검증

- 최신 활성 문서 2,651건 전처리. 제품 신호가 있는 기업 925곳, **기본 선택 제품에서 후보가 나오는 기업 182곳**. 다른 제품 선택 시 후보가 달라진다. 이 수치는 전체 업종 지원률이나 의미 정확도가 아니다.
- 삼성전자→SK하이닉스(DRAM), 농심→삼양식품(라면), 한국타이어↔금호타이어(타이어), LG화학→롯데케미칼(화학 제품), 코스맥스→화장품 업체 등 여러 업종에 같은 선정 절차 적용. 기가비스는 인텍플러스·펨트론.
- 표의 합계, 병합 행 사용처 열, NAND용 프로브카드, 가격표가 후보 제품으로 들어가는 오류를 테스트로 막았다. 최신 공시·규칙 버전·선택 제품 조건과 늦게 도착한 화면 응답도 검증한다.
- 서버 규칙·DB·API 등록 24개와 Flutter 6개 테스트 통과. 서버/Flutter 정적 분석 이상 없음. 실제 브라우저에서 삼성전자 DRAM→NAND 전환, 기가비스 비교, 390px 근거 대화상자와 원문 펼침을 확인했다.
- 기존 연구 테이블의 모델 정의가 현재 체크아웃에서 누락돼 최초 미적용 마이그레이션에 삭제가 포함됐다. 해당 생성 산출물은 `output/peer-candidates/unapplied-*`에 보관하고 registry에서 제외했다. 기존 reports-hardening 작업 트리의 동일 모델 정의 3개를 복원한 뒤 신규 peer_profile 테이블만 생성하는 마이그레이션을 다시 생성·적용했다. 연구 테이블 데이터 삭제 없음.
- 공개 API와 공유하는 서버에는 적용됨. 공개 Flutter 웹 번들은 배포하지 않았다.
