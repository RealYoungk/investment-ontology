# 한국토지신탁 자체 FY2021–22 Source 충돌

실제 접수번호는 FY2021 20220316000546, FY2022 20230323000917이다. 양 연도 연결/별도 네 원문의 현재 기간을 직접 읽어 다음 충돌을 고정했다. 단위는 원문 백만원이다.

- FY2021 CFS: 현재 CE 지분법자본변동 총계 `(8,4730`는 malformed. BS/CE 지배지분 1,020,551/1,020,552 및 비지배 4,265/4,264.
- FY2021 OFS: 현재 BS 현금 338,185, CF 기말 338,186. CE 자본조정·OCI가 BS와 각각 1백만원 차이.
- FY2022 CFS: BS 현금 271,373, CF 기말 271,374. 전체 BS 자본 1,024,933, CE 기말 1,024,932.
- FY2022 OFS: 현재 BS 현금 250,347, CF 기말 250,348. 자체 비교 BS 현금 338,185, 현재 CF 기초 338,186.

별도 원문에는 회사 고유계정과 `신탁계정`의 BS/PL이 함께 인쇄된다. 신탁계정의 숫자로 회사 값을 대체하지 않았다. 반올림 원인을 단정하거나 허용 오차를 추가하지 않았다. 수치 복구 및 noData 승인은 없다.

각 corp/receipt/basis/current period/URI/cover SHA/body SHA/physical cells가 정확히 일치할 때 기존 KnownAnnualSourceConflict 경로로 원인을 반환한다. 현재 수집 실패 상태 및 facts 미저장 상태를 유지하고 source audit용 근거를 제공한다. 다른 issuer/period/changed source에는 이 판정을 적용하지 않는다.

순수 테스트20개 통과, 변경 Dart3개 분석 정상. DB0. 정상 수집 저장 테스트는 부모 통합 슬롯에서 수행해야 한다.
