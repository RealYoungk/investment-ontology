# 기업 찾기 카드 복수 선택

조건 카드를 여러 개 선택하면 모든 조건을 만족하는 기업을 조회한다.
상한(PER, PBR, 부채비율, 배당성향)은 가장 작은 값, 하한은 가장 큰 값을 적용한다.
같은 카드를 다시 누르면 해제하며 남은 카드에서 조건을 다시 계산한다.
첫 카드 선택은 기존 수동 숫자 조건을 교체한다. 시장과 정렬은 유지한다.
숫자를 직접 수정하거나 개별 지표 배지를 지우면 카드 선택을 해제하고 현재 숫자 조건을 유지한다.
URL의 presets에 선택 ID를 기록하고 기존 숫자 파라미터/API 계약은 유지한다.
빈 결과에서도 선택은 유지하고 기존 조건 완화 안내를 제공한다.

검증: 전체 analyzer, 기존 필터/스크리너 회귀 및 AND 결합·상하한 복원·URL·빈 결과 상호작용 테스트.
로컬 실제 브라우저에서 두 카드 선택 시 per=12, roe=10, margin=10 결합과 결과 조회를 확인했다.
서버와 생성 클라이언트 변경 및 DB 마이그레이션은 없다.
