# 지분 흐름 비교 선택 배치

사용자 피드백에 따라 비교 주주 선택 accordion을 제거하고 차트와 동일한 DataPanel 안에 항상 표시했다. compact 지분 흐름에서는 각 선택 항목에 이름·주식 종류·유효 공시 기간·시작/끝 지분율 및 변화를 함께 표시해 별도의 변화 요약과 중복하지 않게 했다. 체크박스는 가로 Wrap, 좁은 폭에서는 주어진 폭 내에서 줄바꿈한다.

최대 6명, 기간 중 5% 이상 기본 선택, 초기화, 주식 종류 구분, 미확보 기간 및 null 단절을 유지했다. 기본 ShadCheckbox/Button과 기존 서비스 DataPanel을 사용했다. 비 compact 화면의 보유량/지분율 전환 및 집계 기준도 유지했다. 데이터나 출처/인증을 변경하지 않았다.

변경 범위 analyze 오류 없음. 기존 지분/스냅샷/디자인 경계와 신규 320/1045px 항상 보이는 선택·선택 해제 테스트 포함 14개 통과. release Web build 42.2초 통과. 운영 배포는 하지 않았다.

실제 최종 빌드의 로컬 1045px 아크릴 지배구조에서 차트와 선택/변화 요약이 동일 박스에 들어감을 확인했다. 염익준 추가 선택으로 2/6→3/6 및 차트 범례/선택 요약 갱신 확인. 이 로컬 데이터는 2026년 반기 주주 값이 미확보 상태로 운영 화면과 다르며, 이를 수집 완료로 해석하지 않는다. 이미지: outputs/design/ownership-layout-2026-10-05/combined.jpg. 기존 개발 앱 캐시 오류로 release 프리뷰에서 확인했으며 임시 탭/프리뷰/viewport를 정리했다.
