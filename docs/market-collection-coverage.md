# 시세·지수 수집 현황의 의미

시세 수집은 실행일 KST 기준 최근 5년의 평일을 대상으로 한다. 거래일 값뿐 아니라 0건으로 확인된 휴장일 장부도 완료에 포함한다. 이미 저장된 범위 밖의 과거 값은 지우지 않는다.

데이터 페이지의 확인 범위 끝은 실제 가격 행이 있는 최신 기준일이다. 시작일부터 그 날짜까지의 평일 수를 분모로 하며 시세·지수 장부를 각각 센다. 두 장부 중 하나라도 없는 날짜는 확인 범위 미완료 한 날짜로 센다. 최신 저장일 뒤부터 어제까지의 평일은 최신 이후 미확보로 별도 표시한다. 원천 API를 직접 확인하지 않은 상태이므로 게시 지연이나 휴장이라고 단정하지 않는다.

최신 가격 종목 수는 최신 기준일 실제 가격 행의 서로 다른 securityId 수다. 최신 지수 수도 실제 최신 지수 행의 수이며 지수 기준일은 가격 기준일과 달라질 수 있다. 역사 전체 Security 수는 현재 종목 수가 아니다.

기존 서버가 새 nullable 집계 항목을 제공하지 않으면 집계 대기를 표시한다. 이전 수나 0을 대신 표시하지 않는다. 이 집계는 읽기 전용이고 원천 API를 부르지 않는다. 실제 수집은 정상 관리자 요청 또는 매일 18:00 KST 기존 정기 작업으로 수행한다. 예산 소진 시 기존 00:10 재개를 따른다.
