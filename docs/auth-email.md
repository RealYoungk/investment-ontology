# 알파인더 인증 메일

가입 및 비밀번호 재설정 메일은 서버에서 Resend API로 발송한다. 맥북 호스팅도 외부 HTTPS 연결과 발신 도메인 설정이 있으면 사용할 수 있다.

## 운영 설정

1. Resend 계정에서 소유한 발신 도메인을 등록하고 제공되는 DNS 레코드로 인증한다.
2. 해당 도메인 발송 권한의 API 키를 만든다.
3. 서버 환경에 `ALFINDER_MAIL_API_KEY`, `ALFINDER_MAIL_FROM`을 설정한다. 발신 주소 예: `알파인더 <noreply@alfinder.kr>`. 실제 검증된 도메인의 주소를 사용한다.
4. 또는 gitignore된 서버 `config/passwords.yaml`의 `shared`에 `authMailApiKey`, `authMailFrom`을 설정한다. 키를 채팅·커밋·스크린샷에 포함하지 않는다.
5. 실행 중인 Serverpod를 재시작한다. 회원 관리에서 발송 설정 상태를 확인한다.
6. 실제 수신 가능한 별도 일반 계정으로 가입 → 인증번호 수신 → 로그인 → 비밀번호 재설정 수신을 확인한다. 스팸함도 확인한다.

설정 존재 표시는 실제 배달 성공을 의미하지 않는다. DNS 인증, 공급자 제한 및 실제 수신을 별도로 확인해야 한다. 현재 구현 테스트는 모의 HTTP 전송과 권한 검증이며 실제 수신 테스트를 대신하지 않는다.

## 동작

- 인증번호는 15분 유효하며 가입/비밀번호 재설정 메일 제목을 구분한다.
- 발송 설정이 없거나 공급자 요청이 실패하면 요청을 실패 처리한다. 콘솔에 인증번호를 출력하지 않는다.
- 요청 제한·인증 실패 제한은 Serverpod 이메일 인증 라이브러리를 사용한다.
- 발송 실패 로그에는 HTTP 상태 코드만 기록하며 인증번호, 메일 본문, API 키, 공급자 응답 본문은 기록하지 않는다.
- API 문서: https://resend.com/docs/api-reference/emails/send-email
