# 시장 원천 공개 대기 재확인

금융위원회 주식시세 API의 공공데이터포털 원문은 기준일 다음 영업일 13시 이후 갱신을 안내한다. 거래소 휴장일과 제공기관의 관공서 공휴일은 동일한 달력이 아니다. 공개 시각은 재확인 예상 시각이며 실제 공개나 입수를 보장하지 않는다.

`MarketPublicationTiming`은 제공기관 안내와 직접 읽은 2026 월력요항 본문의 공휴일 일부만 사용한다. 완전한 관공서 달력으로 주장하지 않는다. 모르는 휴일은 더 일찍 재확인하며 KRX 전용 근로자의 날/연말 휴장일을 제공기관 휴일로 사용하지 않는다. 예상시각 계산은 빈 응답을 휴장이나 원천 부재로 확정하는 근거가 아니다.

최근 기준일의 빈 응답은 기존 정상 일일 수집과 한정된 재확인 큐로 남긴다. 긴 연휴로 기존 3일 유예가 지났어도 예상 공개 후 하루까지 재확인 대기 상태를 유지한다. 기존의 더 이른 일일 큐, 취소, 예산, 24시간 재확인 상한을 보존한다.

2026-10-03 전수 읽기 감사: 2021-10-03~2026-10-02 평일 1305개 중 가격·지수 1222일 저장, 실제 KRX 공식 연도별 달력과 일치하는 휴장 82일, 2026-10-02 한 날짜는 공개 대기다. 10월 5일 관공서 공휴일을 반영한 다음 재확인 예상은 10월 6일 13시 KST 이후이며 입수 날짜 약속이 아니다. 엑시큐어하이트론의 DART/상장종목 법인번호 충돌 한 건은 해결되지 않았다. 두 공식 입력 중 하나를 임의로 정답 처리하거나 기존 연결을 덮어쓰지 않는다.

근거 원문 및 SHA는 `test/fixtures/market_publication/source-proof.json`에 있다. 전체 읽기 SQL와 실제 결과는 주 체크아웃의 `outputs/filing-collection-priority/non-financial-completeness-final-readonly-20261003/`에 보존했다. 순수 테스트 14개와 정적 분석은 통과했다. 새 정상 수집 DB 회귀 3개는 다른 배포 검증의 DB 독점 때문에 작성만 했으며 아직 실행하지 않았다.
