# 연구 데이터 확장 — 2026-10-01 구현 및 검증 상태

## 구현한 범위

모든 기업 페이지가 같은 `ResearchSection`과 `research` API를 사용한다. 삼성전자 전용 분기는 없다. 저장된 자료 읽기는 공개, 수집·자료 반입은 `OntologyAccess.requireAdmin`을 거친다.

| 자료 | 수집/연결 | 표시 |
| --- | --- | --- |
| 임원·주요주주 보유변동 | DART `elestock`, `majorstock` | 보고일, 보유 수량 변화, 지분율 변화, 보고 사유, 원문 |
| 유상증자·CB·BW·EB | DART 주요사항보고서 4종, 최근 5년 | 조달 목적, 발행 조건, 공시 주식 수, 기존 주식 대비 비율 |
| 자기주식 결정 | 취득·처분·신탁 체결·해지 4종, 최근 5년 | 예정 수량/금액, 기간, 목적, 원문 |
| 자기주식 실제 변동 | 기존 정기보고서 typed 자료 | 기초 + 취득 - 처분 - 소각 = 기말의 수량 차트 |
| 컨센서스·수급·공매도·프로그램·신용·대차 | 검증된 공급 자료 반입 계약 및 UI | 종목/기간/연결별 시계열, 확인 가능한 입력의 실적 서프라이즈 |

마지막 행은 실제 공급원이 연결됐다는 뜻이 아니다. 컨센서스 무료 자동 수집원은 아직 확보하지 못했다. KIS 후보 어댑터는 설정과 서비스 제공 권한 확인이 필요하다. 프로그램·신용·대차는 자료 반입을 지원하며 자동 수집기는 없다.

## 값 해석 및 저장 규칙

- 보고 수량 증가를 매수, 감소를 매도로 단정하지 않는다.
- 주요사항보고서는 결정이며 실행 완료가 아니다. EB를 신주 발행으로 분류하지 않는다.
- 누락값과 0을 구분한다. 자기주식 상세행과 합계를 더하지 않는다.
- CB/BW 여러 공시를 더해 현재 미전환 잔액을 만들지 않는다. 정정/상환/전환을 연결한 잔액 계산은 미구현이다.
- 각 공시의 원문 접수번호와 원 응답을 보존한다. 수집 그룹 일부가 실패하면 이전 성공 스냅샷을 유지한다.
- 입력 정수는 문자열/BigInt로 처리한다. 동일 기업 저장을 직렬화하고 동일 자료 재시도는 중복 저장하지 않는다. A→B→A로 회귀한 값은 새로운 관측으로 저장한다.
- 읽기 전용 DB에서는 외부 API 호출 전에 중단한다.

## 전 기업 수집

`research.collectBatch`는 상장 기업 코드를 정렬하여 최대 5개씩 처리한다. 실패 회사 직전 커서를 반환한다. `scripts/ops/collect_research.py`는 기존 관리자 토큰을 환경변수로 받아 커서 파일로 재개한다. 리다이렉트에 토큰을 전달하지 않는다. 자동 일일 스케줄 등록은 아직 없다.

대량 수집 전 운영 DB와 개발 DB가 같은 DART 키의 일일 한도를 따로 집계하는 문제를 확인해야 한다. 복제 DB의 오래된 사용량만 보고 전량 수집하면 안 된다.

## 검증 및 남은 작업

- 서버 정규화·정수 정밀도·생성 코드 등록: 12개 통과.
- Flutter 320px 실제 공시 17건 렌더링, 탭 전환, 자기주식 기본 선택·검산, 미수집/빈 결과 구분, 디자인 경계: 8개 통과.
- 격리된 테스트 DB의 공개 읽기·관리자 전용 쓰기·스냅샷 회귀 통합 테스트 통과.
- 서버 연구 모듈 및 Flutter 연구 화면 정적 검사 통과.
- 개발 서버를 사용자 승인으로 재시작하여 `research` API 생성 누락을 복구했다.
- 사용자 승인 후 별도 `investment_ontology_dev` DB 복제 및 앱 연결 완료. 원본 읽기 전용 유지, 개발 쓰기 롤백 검증과 핵심 건수 대조 통과. 사용자가 로그인한 관리자 화면을 통해 신규 공시 수집을 실행했다. 자세한 내용은 `local-development-database.md`.
- 로컬 Flutter 8100에서 실제 관리자 수집과 시각 검증을 완료했다. 삼성전자 자사주 15건·임원 보유변동 3,382건·대량보유 41건, SK하이닉스 자금조달 2건을 개발 DB에 저장했다. 공개 API 읽기로 건수 및 모든 DART 원문 링크를 대조했다. 전 기업 일괄 수집은 실행하지 않았다.
- 실제 여러 기업 자료 대조, 전 기업 수집, 자동 갱신, 미전환 잔액, 자기주식 결정별 실행 대조, 공급원 미연결 항목이 남아 있다. 전체 완료로 보고하지 않는다.

공식 API 명세: [DART 주요사항보고서](https://opendart.fss.or.kr/guide/main.do?apiGrpCd=DS005), [대량보유 보고](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019021).

## 실제 자료 검증 후 보완

- 자기주식 차트 기본값을 값 없는 신탁 소계에서 유효한 총계로 변경. 전 항목 누락 행은 차트 선택지에서 제외하되 원자료는 유지한다.
- 회사 탭 전환 시 다른 종류의 자료가 남던 상태 재사용 오류 수정.
- 기타주식 예정금액과 결정일/접수일 구분 표시. 교환가 111,180원을 축약 없이 표시.
- 대량보유 수치를 보고자 개인 지분으로 오인하지 않도록 보고서 합산 보유량임을 표시.
- 실제 DART 응답을 `test/fixtures/research/`에 보관해 모바일 회귀 테스트에 사용. `tool/research_sample.dart`는 제한된 공식 API 표본 조회만 수행하며 DB 쓰기는 하지 않는다.
- 화면 증거: `outputs/company-events/skhynix-capital-ui.png`.
- 재시작 중 로그인 갱신 성공 직후 실패 및 signOutDevice 호출을 관찰했다. 재로그인 후 페이지 이동과 수집은 정상이다. 동시 실행/재시작 관련 원인은 확정하지 않았고 인증 정책은 변경하지 않았다.
