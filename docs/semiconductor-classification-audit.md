# 반도체 분류 검증 — 2026-10-01

## 확인된 결함과 수정
- 기존 v1에는 IP·디자인하우스 규칙 없이 설계 소프트웨어만 있어 메뉴의 범위를 구현하지 못했다.
- v2는 사업 개요/주요 제품 절의 자기 사업 문장을 규칙으로 읽는다. 회사명 목록으로 분류하지 않는다. 고객·매입·자회사·계획·부정문을 제외하고 원문 근거를 유지한다.
- IP(영상/인터페이스/메모리 시스템)와 디자인하우스, 팹리스의 사업 형태를 구분한다. 단순 IP 보유를 판매 사업으로 보지 않는다.

## 검증
- 분류 단위 테스트 13개 통과. 실제 공시 문장 21개와 구매·자회사·계획·고객사 오분류 방지 사례 포함.
- 로컬 API와 브라우저에서 설계 IP·디자인하우스 9곳 확인. 운영 배포 전 상태.
- 로컬 DB 읽기 전용 동결 유지. 서버 로그의 세션/헬스체크 정리 쓰기 오류는 기존 동결 설정에 따른 것으로 조회 응답은 정상이다.
