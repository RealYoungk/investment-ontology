# 재무 기준 자동 선택과 예외 처리 (2026-09-28)

## 선택 규칙

기업 상세의 기본값은 **자동**이다. `FinancialBasis.ctes`를 기업 상세·스크리너·기업 비교에서 공통 사용한다. 값의 크기나 흑자 여부로 기준을 선택하지 않는다.

1. 정정으로 대체되지 않은 보고서만 사용한다. 같은 기준·기간의 중복은 최신 접수번호/ID 하나로 정한다.
2. 최신 연도·분기를 우선한다. 오래된 완전한 자료로 최신의 빈 값을 가리지 않는다.
3. 같은 최신 기간이면 연결을 우선한다. 별도가 연결에서 확보한 계산 입력을 모두 갖추면서 누락 입력 또는 일관된 ROE 계산을 추가로 확보할 때만 별도로 전환한다. 연결과 별도 기간을 섞지 않는다.
4. 양쪽 모두 부족하거나, 별도로 전환할 때 다른 입력을 잃으면 연결을 유지하고 계산 불가 사유를 표시한다.
5. 수동 연결/별도 요청은 자동 선택보다 우선한다. 요청한 기준이 없다고 다른 기준을 조용히 반환하지 않는다. 자동으로 돌아가면 다시 자료 상태로 판단한다. 연결 이력이 채워지면 자동은 연결로 복귀한다.

재무 기준 선택은 **수집 자료의 상태**에 대한 판단이다. 연결 자료 미수집을 해당 회사가 연결 공시를 하지 않는다는 뜻으로 표시하지 않는다.

## 계산과 표시

- 최근 12개월: 전년 연간 + 당기 누적 - 전년 동기 누적. 연간 보고서는 연간 값. 빠진 항목은 0으로 대체하지 않는다.
- 연결은 지배주주 순이익·자본 우선. 없으면 동일한 연결 기준의 전체 값을 사용하고 상세 계산 근거에 실제 항목명을 표시한다. ROE의 분자·분모는 지배주주끼리 또는 전체끼리 맞춘다.
- 순이익 0 이하의 PER, 자본 0 이하의 PBR/ROE, 자료 부족, 금액 단위 확인 불가를 구분한다. 음수 순이익 자체는 수집 누락이 아니며 양수 자본에 대한 음수 ROE는 그대로 제공한다.
- 상단 지표·개요 차트·재무 탭은 같은 선택을 따른다. 기준 전환 시 연간/분기 선택은 보존하며 오래된 응답은 버린다. 전환 실패 시 이전 값·기준과 재시도 안내를 유지한다.
- 누락 기간은 한 줄로 모아 표시한다. 계산 근거는 지표 클릭, 부가 설명은 펼치기로 확인한다.
- 스크리너는 별도 적용 기업명에 `별도`를 표시한다. 비교 표에 실제 기준/자동 선택 이유와 보고 기간을 표시하며 결측 지표의 사유는 툴팁으로 확인한다.
- 업종 비교는 자동 선택한 연결/별도 기준이 같은 기업끼리 계산한다. 상세에서 수동 선택하면 자동 업종 비교와 다를 수 있음을 비교 기준에 명시한다.

## 검증 범위

- 서버: 새 기준 선택 12개(자료 없음·명시 요청 없음·흑자/0/적자·전년 동기 누락·입력 손실 방지·양쪽 불완전·오래된 별도·최신 별도·정정 제외·세부 계정 제외·연결 복귀), 기존 재무/시장 5개, 스크리너 21개, 생성 코드 3개.
- Flutter: 재무 계산·기준 전환·디자인 경계 및 스크리너 상호작용 테스트. 전체 순이익과 지배주주 자본을 섞지 않는 ROE와 차트 회귀를 포함한다.
- 실제 API 표본 11개사(연결/별도/연결 부족/적자 포함)의 PER·PBR·ROE·영업이익률·부채비율·FCF 수익률을 Flutter 계산과 대조했다. 이는 전체 기업의 공시 원문 정확도 검증이 아니다.
- 기가비스: 자동은 별도, 수동 연결은 `2025 반기 누적 자료 부족`, 자동 복귀 시 별도 PER 74.86배. 삼성전자는 연결을 유지한다. 시세 기준일 2026-09-23.
- 실제 데스크톱·390px 브라우저에서 선택/복귀/계산 근거/기업 비교를 확인했다. 전 기업 첫 계산은 성능 수정 후 약 4.7초, 이후 캐시 사용.
- 실행 증거: `output/financial-basis-20260928/`의 로그·실제 데이터 표본·대조 테스트.
