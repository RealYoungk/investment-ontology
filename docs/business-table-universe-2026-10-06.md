# 상장사 전수 실행과 AI 원문 대조 — 2026-10-06

## 판단

아직 ‘상장사 대부분의 보고서 정보를 정확히 시각화한다’고 판정할 근거는 부족하다. 전수 실행 안정성과 정보 누락률·정확도는 별개다. 이번 수치는 저장된 과거 본문 스냅샷을 대상으로 하며 최신 운영 전체 DB의 상태를 뜻하지 않는다.

## 전수 실행

`outputs/business-visuals/all-company/readonly-source-snapshot.jsonl`의 2,759개 상장사에 추가 표 추출기 `BusinessTableInsights`를 실행했다. 저장 본문 2,721개는 실행 예외 0건. 저장 본문이 없는 38개는 실패나 원문 부재로 단정하지 않았다. 2,314개 기업에서 추가 표 8,053개를 반환했다. 기존 매출·생산·수주·연구개발비 등 DocumentFact 추출기는 이 집계에 포함하지 않는다.

이 스냅샷의 본문 접수번호가 최신 공시 접수번호와 같은 기업은 188개다. 대부분 연간 본문으로 검사됐으므로 최신 반기까지 커버한다고 표현할 수 없다. 원본 파일 취득 자료는 별도로 있지만 이번 전수 실행에는 서버 저장 본문만 사용했다.

재실행: 서버 패키지에서 `dart run tool/business_tables/audit_universe.dart ../outputs/business-visuals/all-company/readonly-source-snapshot.jsonl ../outputs/business-table-universe`.

## AI 채점 범위

Codex AI가 실제 원문 표를 읽고 표의 목적, 행, 기준 숫자와 단위를 정답 기준으로 작성한 다음 출력과 대조했다. 같은 AI가 구현과 평가를 수행했다. 독립 모델 이중 채점이나 전수 원문 검수는 수행하지 않았다. 성공 사례만으로 점수를 높이지 않도록 확인된 누락도 포함했다.

수정 대상으로 선정한 6개 표 형태는 행 보존·기준 금액·단위 확인 모두 통과했다. 그러나 이미 확인한 미지원 표 3개를 포함하면 이번 목적 표본의 형태 커버리지는 **6/9**다. 무작위 표본이 아니며 상장사 전체 정확도로 일반화하면 안 된다. 각 표 전체 셀·본문 전체 사실의 정확도는 미측정이다.

## 검증과 남은 작업

변경 파일 정적 분석 문제 없음. 실제 원문 회귀 6건을 추가했고 기존 회귀·생성 등록 검사를 포함해 50개 테스트 통과. 서버 MCP에서 자동 재컴파일/리로드 성공을 확인했다. 이번 변경은 서버 규칙만이며 화면 전체 상호작용이나 운영 배포를 검증했다는 뜻이 아니다.

시장×업종 코드 763개 층에서 최대 3개씩 선정한 후속 대조 대상은 1,383개다. 표가 없거나 본문이 없는 기업을 먼저 포함했다. 목록 생성은 원문 검토와 다르며 이 목록은 아직 미채점이다. 전체 신뢰도를 판정하려면 최신 본문 연결, 기존 DocumentFact와 추가 표의 통합 누락률, 업종별 수치·단위·기간·회사 범위 대조, 화면 표시까지 확인해야 한다.

근거 파일: `outputs/business-table-universe/summary.json`, `ledger.json`, `ai-source-review.json`, `stratified-review-queue.json`, 기업별 `.parsed.json` 및 `.live.json`/`.annual-live.json`. AI 원문 대조 점수는 서비스의 verified 사실이나 사용자 검수 결정으로 DB에 쓰지 않았다.


## 같은 날 후속 수정 완료

위 기록은 최초 검사 시점의 결과다. 남겨둔 세 표를 후속 수정했다.

- 미코: 기수 열 + 주요매입처 + 바로 뒤 ‘당기 매입액’ 설명을 인식해 TUBE 32,258 백만원을 추출한다. 기수는 제27기에 고정하지 않는다.
- 선익시스템: 계약 상대방/항목/내용 3열과 2열 이어지는 행을 계약별로 묶는다. 평택도시공사 23,615,140,000원, 태흥개발 외 19,000,000,000원을 계약일과 함께 보존한다.
- 기가비스: 지수/세전 이익 영향 → 당반기/전기 → 상승/하락 조건의 다단 구조를 인식한다. 음수를 유지하며 누락 표시 `-`를 0으로 바꾸지 않는다.

선정한 원문 9개 표 형태는 이제 9/9 통과다. 이는 전체 상장사 정확도 100%를 뜻하지 않는다. 전수 재실행은 동일 2,759개 스냅샷, 추가 표가 있는 기업 2,318개, 표 8,078개다.

최신 본문 누락으로 조회 자체가 비던 문제는 저장된 이전 본문을 반환하되 응답 제목과 화면 안내에 **이전 저장 보고서 / 최신 본문 수집 대기 / 실제 반환 출처**를 명시하도록 수정했다. 최신 제품 프로필 선택은 그대로 유지하며 과거 제품을 최신 제품으로 부활시키지 않는다. 특정 연도를 요청하면 그 연도 최신 본문이 없는 경우 계속 null이며 다른 연도로 넘어가지 않는다. 최신 본문 자체의 수집이 완료됐다는 뜻은 아니다.

서버·DB 통합 및 회귀 60개, Flutter 10개 검사 통과. 안내문 320px 및 기존 표 320/768/1280px 검사 포함. MCP에서 서버 재시작 성공을 확인하고 로컬 API를 다시 호출했다. 미코/선익/큐알티/스피어는 최신 요청에서 실제 2025년 저장 본문과 대기 표시를 반환하고 표 3/4/3/3개를 보여준다. 기가비스 최신 반기는 표 5개를 반환한다. 응답 근거는 기업별 `.live-fixed.json`이다. 실제 브라우저 상호작용 전체 검사와 운영 배포는 수행하지 않았다.
