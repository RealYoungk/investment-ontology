# 정기보고서 수집 범위와 최신 사업 본문 우선수집

사용자 결정(2026-10-02): 재무 데이터는 기업별 최근 5개 사업연도의 연간 사업보고서와, 그 이후 최신 정기보고서가 분기·반기일 때 그 한 기간만 수집한다. 과거 모든 중간보고서나 자동 10개년 확장은 대상이 아니다. 기존 장부와 저장 데이터는 삭제하지 않는다.

수집 대상, 남은 작업, 데이터 페이지 분모와 주요정보 수집의 재무 백로그 판단은 동일한 범위를 사용한다. 기간별 최종 정정 접수번호를 선택한다. 전체 주요정보 28종의 기존 장부 분모는 재무 분모와 구별한다. 저장 완료와 원천 데이터 없음 응답은 처리 건수이며, 실패는 미완료로 남는다.

최신 사업 본문은 주요정보 핵심 항목보다 먼저 수집한다. 기업별 사업연도·보고서 기간·정정 접수번호로 최신 보고서를 확정하며, 최신 본문이 저장됐다고 이전 연간 본문을 다시 우선수집하지 않는다. OpenDART 일일 예산을 유지한다. 원본 취득 실패나 한도 소진 시 공개 DART의 실제 사업 본문을 취득할 수 있다. 공개 경로는 공식 호스트, 접수번호, 문서 좌표, 본문 제목, UTF-8, 내용 길이를 검증하고 URL·본문 SHA256을 Source에 보존한다. 최소 1초 간격과 실행당 시도 상한, 6회 연속 실패 중단, 취소를 적용한다.

공유 데이터 변경은 기존 관리자 권한 검사를 유지한다. 운영 수집은 iwinv Serverpod에서 실행한다. 별도로 맥에 확보한 자료는 운영 DB 저장과 구별하며, DB 직접 삽입이나 권한 우회 없이 처리한다. 첨부 정정은 최신 접수번호와 실제 사업 본문의 이전 접수번호를 구별한다.

일반 기재 정정의 본문 취득 실패는 이전 본문으로 최신 확보를 확정하지 않는다. 이전 접수 본문 연결은 명시적인 첨부 정정에 한정한다. 일시적인 공개 취득 오류는 실패와 재시도로 기록하며 자료 없음으로 처리하지 않는다.

데이터 페이지는 최신 접수번호와 정확히 일치하는 본문 확보 기업과 어느 기간이든 본문을 보유한 기업을 분리한다. 첨부 정정의 이전 접수 본문은 최신 직접 확보 건수에서 제외한다. 최신 집계가 없는 구버전 응답은 집계 대기로 표시한다. 본문 확보와 지표 추출 완료는 별개다.

운영 DB 읽기 전용 확인(2026-10-02): 새 범위 15,142건(연간 12,531, 반기 2,585, 1분기 17, 3분기 9), 미완료 1건. 코스나인의 2024 연간 요청에 DART가 2025 연간 응답을 반환한 기간 불일치 때문에 실패로 남았다. 이 응답을 2024 데이터로 강제 저장하지 않는다. 이 수치는 확인 시점의 스냅샷이며 전 기업의 모든 수치 확보를 의미하지 않는다.
