# 전환사채 잔액 추이와 해소량

2026-10-02 사용자 요청: 전환사채 추이를 대조해 해소량을 추정하고 투자자가 읽을 수 있는 정보로 제공한다.

## 화면과 해석

기업 지배구조에 `전환사채 잔액은 얼마나 줄었나?`를 둔다. 보고서 기준일의 잔액, 비교 기간의 순감소, 남은 전환 가능 주식, 수집 상태를 먼저 표시한다. 회차별로 기준일·잔액·전환가액·가능 주식과 원문을 연결한다. 원천이 비어 있거나 비교 불가능하면 이유를 표시하고 0으로 채우지 않는다.

잔액 감소는 전환·상환·소각을 구분하지 못하는 **순감소 추정**이다. 전환 청구는 주식 전환 근거이지 시장 매도 근거가 아니다. 만기 전 취득은 재매각될 수 있으므로 영구 해소로 합산하지 않는다. 발행 결정도 실제 발행으로 합산하지 않는다.

## 계산 규칙

- 동일 회사·CB·회차·발행일·주식 종류로 연결한다. 식별자가 누락/중복되면 연결하지 않는다.
- 원 단위 권면 잔액을 비교한다. 회계상 장부금액, 상각·평가 금액은 사용하지 않는다. 원문 단위도 보존한다.
- 같은 기준일은 최신 접수번호의 정정 공시를 선택한다. 미수집 최신 정정 대신 이전 자료를 최신인 것처럼 보여주지 않는다.
- 두 기준일에 모두 확인된 회차만 차감한다. 회차 누락, 표 미확보, 신규 회차는 비교 불가로 표시한다. `해당 없음`은 개별 회차의 상환 사실을 증명하지 않는다.
- 순감소 = 이전 권면 잔액 − 현재 권면 잔액. 음수는 잔액 증가로 표시한다. 가능 주식 수 감소를 해소량으로 바꾸지 않는다(전환가 조정 영향).
- 후속 이벤트 대조 설계(현재 미구현): 이벤트는 실행일이 (이전 기준일, 현재 기준일]인 확정 전환/상환/소각만 원인 분석에 사용한다. 결정·자기사채 취득·재매각·정정 중복은 제외한다. 원인 합계가 순감소보다 크거나 잔액이 증가하면 모순/상계 가능성으로 표시하고 잔여 차이를 음수 해소량으로 만들지 않는다.
- 확인되지 않은 차이는 `원인 미확인 순감소`로 남긴다. 확인된 이벤트가 없으면 전환·상환 금액은 미확인이지 0이 아니다.

## 수집과 운영

조회는 저장 자료만 읽으며 공개 접근을 유지한다. 수집은 OntologyAccess 관리자 검사 후 기존 공시 목록의 최근 5개 연간 보고서와 최신 연간 이후 최신 중간 보고서만 사용한다. 과거 중간 보고서 전체 수집으로 범위를 넓히지 않는다. 원문 수집은 고정 DART URL, 회사·접수번호에 연결된 viewer 본문만 읽는다. 원문·행 근거·출처 URL·수집일을 보존한다. 파생 차이는 조회 시 계산한다.

공식 원천: [OpenDART 전환사채 발행결정 필드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS005&apiId=2020033), [KRX 공시·상장관리 해설서](https://kind.krx.co.kr/external/dst/reference/11499/%28%EA%B3%B5%EC%A7%80%2925%EB%85%84%EC%BD%94%EC%8A%A4%EB%8B%A5%EC%8B%9C%EC%9E%A5%EC%9E%A5%EA%B4%80%EB%A6%AC%ED%95%B4%EC%84%A4%EC%84%9C.pdf). 이벤트별 원문 실행 표가 수집·검증되기 전에는 공시 제목이나 발행결정 API로 원인 금액을 확정하지 않는다.

## 구현 및 검증

지배구조 화면에 잔액 추이 카드, 전체/회차 선택, 기준일별 차이, 수집 상태와 원문 근거를 구현했다. `bond.trends`는 저장된 스냅샷만 공개 조회하며, `bond.collect`는 관리자에게만 허용한다. 기존 capitalStructure 스냅샷을 재사용하므로 새 테이블이나 마이그레이션은 필요하지 않다.

현재 제공하는 해소 정보는 **동일 회차의 권면 잔액 순감소 추정**이다. 전환·상환·소각 이벤트 수집과 원인별 확정 금액은 아직 구현하지 않았다. 원인 필드는 미확인으로 남기며 전환·매도를 확정하는 문구를 사용하지 않는다. 원문이 누락되거나 회차가 사라지면 해당 구간 계산을 보류한다.

재영솔루텍 2022·2023년 공식 보고서 표를 고정 검증 자료로 보존했다. 250억 원 → 227억 원, 동일 회차 합계 23억 원 순감소를 파서·저장·공개 조회·화면까지 대조한다. fixture manifest에 원문 URL과 SHA256을 기록했다. 검증 화면의 숫자는 이 기록 자료이며 운영 DB 수집 완료를 의미하지 않는다.

검증 결과: 서버 23개·Flutter 9개 테스트 통과. 전체 dart analyze 오류·경고 없음(기존 info 26개). MCP hot_restart 완료 후 실제 앱의 bond.trends 성공 로그를 확인했다. 운영 배포 및 운영 DB의 역사 자료 수집은 아직 수행하지 않았다.
