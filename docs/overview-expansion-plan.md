# 전 기업 개요 확장 — 2026-09-30

사용자 승인: 전 기업에 사업 이해와 투자포인트를 확대하고, 바이오·금융 등 다른 사업 구조를 처리한다. 기존 개별 기업 설명은 보존한다. 정적 콘텐츠 운영을 유지하며 DB 스키마와 사용자 데이터를 변경하지 않는다.

## 기준선
- 상장기업 2,756개, 최신 비정정 사업본문 2,725개, 본문 없는 기업 31개.
- 기존 제품 프로필 907개사. 상세 원리 연결은 2개사(구버전 집계 기준).
- 기존 제품 추출은 주요제품 표 중심이므로 금융·바이오·지주·리츠·SPAC을 충분히 다루지 못한다.

## 구현
1. 원문과 회사 분류를 읽기 전용으로 내보내고, 재현 가능한 정적 콘텐츠 생성기와 감사 결과를 만든다.
2. 기업별 사실(사업본문·제품)과 공통 설명(수익 구조·산업의 성장 동인)을 분리한다.
3. 바이오 연구개발과 제약 판매, 은행과 금융지주, 보험과 증권, 리츠와 일반 부동산, SPAC과 실제 영업회사를 구분한다.
4. 회사별 설명과 돈의 흐름 도식을 추가한다. 기존 기가비스·성호전자 설명은 우선한다.
5. 원문 부족 기업에 회사 고유의 제품·계약·성장 사실을 만들지 않는다. 보유한 회사분류 범위의 설명만 제공하며 감사 집계에서 따로 센다.
6. 숫자·가격목표·상승 추천은 생성하지 않는다. 기업별 사건은 원문 근거가 있을 때만 쓰며, 일반적인 사업 동인을 최근 호재로 표현하지 않는다.
7. 자동 검증, 이종 업종 대표기업의 원문 대조, 반응형 UI 및 화면 전환 검수 후 범위와 미충족 부분을 기록한다.

## 반영·검수 결과

- 현재 상장기업 2,756개에 정적 카탈로그 연결. 기존 기가비스·성호전자의 상세 설명 우선순위 유지.
- 57개 모델 정의(미확인 상태 포함), 세 단계 도식, 복수 사업 선택, 업종 성장 동력.
- 회사 근거가 있는 설명/제품 1,568개사. 그 외 1,188개사는 업종 이해 수준. 본문 없는 31개사는 회사 고유 사실을 생성하지 않았다.
- 짧은 원문 문장 999개사, 별도 작성·근거 대조 요약 11개사, 원문과 일치하는 기존 제품 항목 907개사(서로 중복). 이 숫자는 전체 내용의 의미 정확도를 전수 검증했다는 지표가 아니다.
- 보통주 가격·재무·매출 구성·최근소식은 기존 API. DB 쓰기나 유료 AI 호출 없음.
- 은행·보험·증권·금융지주는 헤더 지표 구성을 분리. 리츠·인프라 투자·SPAC은 제조업식 FCF 지표를 헤더에서 제외.
- Python 회귀 9개 통과. Flutter 전체 133개 통과 후 마지막 헤더 선택 수정은 관련 회귀 재검증. 모든 모델을 320/768/1280px 및 1.3배 글자 크기로 렌더링 검사.
- 브라우저 확인: 알테오젠, 삼성전자(사업 전환), KB금융, 삼성생명(390px 세로 도식), 신한알파리츠. 코드 분석과 diff 공백 검사 통과.

### 남아 있는 품질 범위

이 작업은 전 기업의 **초기 설정**이다. 2,756개 기업의 최신 촉매·계약·임상 단계를 개별 조사해 완성한 결과가 아니다. 업종 코드가 넓거나 주사업 변경을 따라가지 못하는 기업, 복합사업 기업은 추가 정교화가 필요하다. 이를 숨기기 위해 공통 성장 동인을 회사별 최신 투자포인트로 꾸미지 않았다. 재현과 수정 경로는 `tool/overview/README.md`에 기록했다.
