# 과거 인쇄 법인명에 대한 동일 원접수 발행인 검증

운영 897 스냅샷의 실패 241개 중 legal issuer 공유 오류는 43기간이다. 공유 lastError만으로 개별 CFS/OFS 실패 원인을 확정하지 않는다. 이번 검토 범위는 GA 20240319000287 OFS, 오건 20230714000217 OFS, PIE 20250324000848 OFS의 기존 공식 shell/표지/재무 원문 9개이며 추가 GET·운영 조회·DB 실행은 없었다.

새 규칙은 현재 회사명과 과거 이름의 유사도나 사명 변경 추정을 사용하지 않는다. 공식 shell의 고유 corpCode와 원접수 문서번호, 고유 표지와 기준별 재무 노드의 실제 6좌표, 표지의 명시 시작·종료일, BS·손익·CE·CF 제목의 직접 인쇄 법인명이 모두 일치해야 한다. 감사첨부는 이 규칙을 적용하지 않고 기존 same-receipt 감사 연결 검증을 유지한다. 기존 금액·단위·기간·전체 손익·BSCE 검산은 변경하지 않았다.

GA의 관악산업주식회사 FY2023 및 오건의 주식회사휴벡셀 FY2022는 각 7개 직접 계정이 통과한다. 선택 CAPEX 총행은 없으며 합산하지 않는다. 테스트 fixture cases.json은 실제 인쇄 계정명과 직접 금액을 고정 검증한다. 현재 masterName과 printedIssuer를 별도로 원문 provenance에 남기며 master 자료나 account_id를 변경하지 않는다. PIE는 표지 FY2024와 현재 기수의 모순으로 거부한다.

같은 규칙은 조건을 충족하는 다른 원접수에도 적용되지만 전체 43기간의 숫자 양성이나 운영 저장 완료를 주장하지 않는다. 원문 reviewed coverage는 위 3접수/3basis에 한정한다. 정상 masterName 일치 경로 및 기존 상세 법적명칭/고유 감사첨부 경로는 유지한다. 새 proof로 성공한 반환값은 동일 proof를 보유해 재파싱 검증이 가능하다.

DB 통합 검증 및 운영 수집은 이번 작업에서 실행하지 않았다. API 시도수/공개 재시도 상한/우선순위/예산은 변경하지 않았다.
