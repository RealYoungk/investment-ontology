# 공식 연결재무제표 비적용 문구 5건

20250321001939(프로젠), 20250321001395(한국미라클피플사), 20250321000819(엔에스컴퍼니), 20250321000661(타임기술)는 FY2024.12, 20240328001866(씨알푸드)은 FY2023.12의 정확한 공식 section2 노드에서 연결 비적용 문구만 인쇄한다. 원문에는 표·숫자·참조 문장이 없으며 공식 shell/표지/노드 URI와 SHA를 fixture proof.json에 보존했다.

새 허용 문구는 정확히 세 가지다.

- `- 당사는 보고서 제출일 현재 해당사항이 없습니다.`
- `당사는 해당사항 없습니다.`
- `본보고서 작성기준일 현재 해당사항이 없습니다.`

엔에스컴퍼니 실제 문구 `- 해당사항 없음.`은 기존 허용 문구를 재사용한다. 하이픈 외 추가 문맥, 상기내역, 외부 참조, 숫자나 표가 붙으면 비적용 예외로 인정하지 않는다. 기존 BODY 전체 일치·section2·회사·접수·표지 실제 기간 검증을 유지한다. 빈 숫자 성공이 아니라 원문 근거를 담은 PublicFinancialHtmlBasisNotApplicable로 기존 수집 경로에 전달한다.

큐 우선순위는 위 5개 정확 접수/회사/회계연도/12월 annual의 CFS만 대상으로 한다. 별도 기준이나 다른 접수는 우선화하지 않으며 기존 저장 상태 및 API 시도 횟수를 변경하지 않는다. 공개 시도 3회 이상은 계속 제외한다. 공식 fixture 양성과 잘못된 section·추가 문장·표·숫자·참조 반례 및 순수 우선순위 테스트를 검증했다. 운영 변경·API키 호출·DB 테스트는 수행하지 않았다.
