# 마지막 연결 비적용 9건

공식 `2. 연결재무제표` 절 전체가 순수 부재 문구인 9개 원접수만 CFS 우선순위에 추가한다. 각 원문은 회사 코드·접수·동일 문서 ID·표지 2021년 1월 1일~12월 31일과 URI/SHA를 독립적으로 대조했다. 아래 두 문구의 경계를 확인했다. 첫 문구는 기존 공백 제거 규칙을 재사용하며 중복 literal을 추가하지 않는다. 실제 신규 허용 문구는 두 번째 한 가지뿐이다.

- `당사는 보고서 제출일 현재 해당 사항이 없습니다.`
- `-. 사업보고서 작성기준일 현재 해당사항 없습니다.`

표·숫자·법률 문맥·추가 문장·참조·다른 절은 허용하지 않는다. 지앤이헬스케어의 `상기 내역과 관련하여` 문장은 제외한다. 메디안디노스틱 연결 손익표의 2021년 1월 1일~2020년 12월 31일 역전 제목도 거부를 유지한다. 숫자나 기간을 추정하지 않는다.

기존 OFS 보고서·사실·Source를 변경하지 않는다. API 시도 3회는 그대로 두고, public 시도 3회 이상은 우선순위에서 제외한다. 새로운 숫자 보고서 저장이나 운영 수집 완료를 주장하지 않는다. typed 비적용은 해당 CFS의 원문 근거를 별도 Source에 보존하는 경로다.

검증: 공식 11건 원문 33개 SHA 대조, 순수 9개 실제 transport typed 부재, 신규 2문구 및 잘못된 회사·기간·basis·숫자·표·참조·절 음성 경계, 제외된 실제 원문 2개. 정상 큐 DB 회귀는 일반 양 basis 실패 10건을 먼저 넣고 순수 9건을 뒤에 넣어도 9건이 먼저 처리되는지 확인하며, 기존 OFS 전체 JSON 불변과 updated 0·API 요청 0을 확인한다.

독립 DB는 일일 DART 사용량 20,000회를 seed하여 목록 및 숫자 API 요청도 0임을 확인한다. API 시도 횟수와 public 재시도 한도를 재설정하지 않는다. 시험용 기존 OFS 보고서·사실·Source는 각 전체 JSON을 전후 비교한다.

최종 결과: 단위 46개 PASS, 정상 큐 독립 DB 1개 PASS, 분석 No issues, 포맷 변경 0. 실제 9개 부재 감사 Source를 보존하고 updated 0, 기존 OFS JSON 불변, API 사용량 소진 상태의 API 호출 0을 검증했다. 운영 DB·API·배포 변경은 수행하지 않았다.
