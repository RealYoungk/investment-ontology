# DB FY2021 별도 원문 신원 묶음

접수 20220316001241, 법인 00115694, 2021.01.01~2021.12.31 별도 기준만 지원한다. 공식 쉘의 자기 법인코드와 동일 문서번호의 표지·회사개요·별도 재무제표 네 원문의 URI 및 SHA를 고정한다. 표지의 DB금융투자 주식회사와 회사개요의 자기명칭 디비금융투자 주식회사/DB Financial Investment는 해당 법인의 같은 접수 문서에 직접 인쇄되어 있다. 전역 음역·별칭 규칙을 만들지 않는다.

캐시 전용 검증 후 기존 전체 재무 파서로 직접 인쇄 8계정과 기간·단위·BS 및 CE 교차증명을 유지한다. 인쇄명, 현재 마스터명, 개요 URL 및 네 SHA는 행 출처 감사에 함께 남긴다. FY2022 저장자료를 바꾸지 않으며 연결 두 원문의 현재열 모호성도 완화하지 않는다. API 재요청·시도 초기화 없이 기존 public cap3의 일회성 캐시 감사 계약을 따른다.

신원 문자열·접수·회사·기준·기간 또는 어느 원문 바이트라도 바뀌면 거부한다. 원문 및 Source의 숫자를 수정하지 않는다.
