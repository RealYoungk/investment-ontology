# 직접 6계정 원문 부분 추출

제주은행 20230314001271 OFS, 삼성증권 20230309000572 OFS, 퓨쳐메디신 20230323001133 OFS의 실제 원문을 검증했다. 첫 두 원문은 전체 매출 합계 단일행을 식별하지 못하며, 마지막 원문은 현재 영업수익에 `-`를 인쇄한다. 매출을 합산하거나 0으로 대체하지 않는다.

원문 표지의 회사·접수·기간·기수와 각 재무표의 현재 열 및 인쇄 단위를 검증한다. 직접 자산·부채·자본·영업손익·당기순익·영업현금흐름 6개만 반환하며, BS 등식과 독립 CE 마지막 전체 총계 열의 당기순익·기말자본 일치를 요구한다. 제주은행 신탁 계정 표와 부모·NCI 구성요소는 전체 회사 값으로 선택하지 않는다. 인쇄 계정명 및 null account_id를 유지한다.

`SourceVerifiedPartialCore.verifiedRows`에는 실제 원문 독립 bodySha256, 표지+재무표 sourceDigest, URL, 회사·접수·기준·연도를 전달해야 한다. 검증된 6행은 재무표 일부 계정 확보이며 전체 7계정이나 연결 기준 확보로 표시할 수 없다. 매출 기반 비율과 성장은 null이어야 한다. Sync 통합 및 DB 저장 검증은 이 커밋 범위 밖이다.

원본 3문서의 SHA·좌표는 각 immutable asset manifest에 보존한다. 실제 퓨쳐메디신 CFS는 기존 span 제한에 불통과하며 OFS를 연결 값으로 재사용하지 않는다.
