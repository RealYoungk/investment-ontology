# CE 날짜 표기 공통 회복

검토 대상은 과거 core/balance 실패 50접수의 100기준 로컬 원문입니다. 현재 운영 실패 수나 저장 완료 수를 의미하지 않습니다. 새 GET, DB 실행, Sync 변경은 없습니다.

원문 CE의 Roman 항목 번호 뒤 실제 날짜를 읽습니다. 당기초는 원문에 인쇄된 실제 시작일과 같아야 합니다. 전기말을 당기초로 대체하지 않습니다. 같은 자본변동표 아래 전기·당기 표가 이어지는 경우 해당 제목 아래 고유한 명시 단위를 사용하고, 당기 종료일 없는 전기 표는 검산 대상으로 채택하지 않습니다. 당기말·기말자본은 실제 종료일과 일치해야 합니다. 총계 열의 당기순손익·기말자본은 각각 주 손익표·BS 값과 독립 비교합니다. 부모/NCI 열, 단위나 날짜의 추정은 추가하지 않았습니다.

기존 100기준 순수 실행 15통과를 유지하면서 신한 FY2021/2022 CFS·OFS, JB FY2021/2022 OFS, KB FY2021/2022 OFS, 한국캐피탈 FY2022 CFS·OFS 10기준이 추가 통과했습니다. 이는 매출 직접 총행 미확보 상태의 6계정 부분 원문 파싱 결과입니다. 재무 전체 완료나 매출 보유를 주장하지 않습니다.

실제 3개 OFS 원문을 고정 fixture로 보존하고 6개 직접금액 및 원문 현재 CE 라벨을 검증합니다. 메디젠·다원 FY2021의 인쇄 CE 종료일 모순 원문은 교정 없이 거부합니다. 후속 Medizen2022 빈 머리글 및 유한 조정주석 지원은 별도 작업입니다.
