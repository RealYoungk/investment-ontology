# SK시그넷 FY2024 별도 원문 복구

대상은 회사 01188730, 접수 20250320001633, 연간 2024.01.01–2024.12.31, OFS 한 건이다. 일반 영문/한글 음역표나 회사별 느슨한 별칭 규칙을 추가하지 않는다.

같은 접수·DCM10440936의 회사개요 전체에는 다음 직접 증거가 있다.

- 법적명칭 절: 2022년3월30일 주식회사 시그넷이브이에서 에스케이시그넷 주식회사로 사명을 변경하였다는 완료형 선언.
- 자기 회사 연혁의 상호변경표: 2022.03 / (주)시그넷이브이 / SK시그넷(주).
- 표지는 에스케이시그넷 주식회사, BS/손익/CE/CF는 SK시그넷 주식회사.

직전명·변경월과 기간 이전 완료일이 일치하는 두 직접 선언을, 해당 원문 SHA와 공식 좌표 전체를 고정해 연결한다. shell의 owncorp는 01188730으로 유일하다. 과거 전회사·종속회사·미래변경·중복행·변경월 불일치·URI/회사/기간 변형은 허용하지 않는다. 원문 4개와 manifest는 assets/financial_source_cache/20250320001633-ofs에 보존했다.

기존 파서는 원문 숫자·계정명·단위·현재열을 그대로 읽는다. 자산230,642,631,079 = 부채335,708,768,291 + 자본(-105,066,137,212). CE whole 현재 순손실(-246,554,897,630)와 기말자본(-105,066,137,212)은 손익/BS와 일치한다. 매출74,401,016,313, 영업손익(-245,159,821,034), CFO(-66,891,998,445) 만 읽히며 accountId는 null이다. 각 행 html_provenance에 직접명칭 증거를 남긴다.

초기 필터 실행은 단위137건과 격리 DB2건 통과했으나 SK 양성 테스트명에 필터 키워드가 없어 그 한 테스트가 제외되었다. 양성 테스트의 8행 기대는 잘못이었다. 전체 SK suite 재실행에서 확인 후 필수7 인쇄계정명·현재금액 각각을 검증하도록 수정했다. 원문은 시설물/기계장치/차량운반구/비품/금형/건설중인자산 등 개별 취득행만 인쇄하며 유형자산취득 합계 단일행은 없다. 이를 합산하여 CAPEX를 생성하지 않으며 FCF도 완결 주장하지 않는다. DB2의 7~8행 범위 검사와 summary 필수7 검증은 실제7에서 통과했다. 정상 admin 금융 큐를 dailyBudget0으로 실행하여 원문 Source/실제계정명/금액/summary, 반대 basis 전체 JSON 불변, 재실행 dedup, SHA 실패 audit 및 동일 cache 재시도 방지, 숫자 publicattempt3/API counter 불변을 확인했다. 운영 DB·SSH·배포·API 호출은 수행하지 않았다. 실제 서비스 저장 완료를 주장하지 않는다.
