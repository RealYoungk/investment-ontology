# 같은 접수의 공식 감사첨부 두 원문

검증 대상은 가이아코퍼레이션 20240401000698/FY2023/OFS와 메디안디노스틱 20220315000038/FY2021/CFS 두 건뿐이다. 두 대상은 2026-10-02 읽기 전용 5개년 금융 수집 범위 원장에서 미완료로 확인했다. 다른 접수·회사·기준·기간으로 확장하지 않는다.

원 사업보고서 손익계산서에는 각각 현재기간 끝이 2022년/2020년으로 잘못 인쇄돼 있다. 그 날짜를 수정하거나 비교값을 당기로 바꾸지 않는다. 현재 접수 viewer의 명시적 감사첨부는 각각 dcm9792565/8458313이며, 같은 접수·회사와 연결된 감사원문 현재 BS/CIS/CF/CE의 실제 날짜는 FY2023/FY2021이다.

main shell, main cover, audit shell, audit statements의 고정 공식 URI와 원문 SHA256을 전부 검증한다. 기존 dcm 동일 규칙의 예외는 이 두 불변 프로필의 원문 해시가 모두 맞을 때뿐이다. 감사 원문의 section-1 `(첨부)재무제표`/`(첨부)연결재무제표`부터 바로 다음 `주석` 앞까지만 읽으며, 이후 기존 현재 열·직접 전체계정·원 단위·손실 부호·BS 회계식·CE 교차 검증은 그대로 적용한다.

두 원문 모두 직접 인쇄된 핵심 7계정과 유형자산 취득 1계정을 확보한다. HTML의 XBRL ID는 null로 유지한다. 저장 Source URI는 실제 감사첨부 dcm이고, 각 원값의 html_provenance 및 별도 수집 감사 Source에 main cover URI/SHA, 감사 shell URI/SHA, 실제 statement URI/SHA 및 main CIS 날짜 충돌을 보존한다. 사업보고서 손익 표제 자체가 정상화됐다는 뜻이나 전체 재무제표 모든 숫자를 수집했다는 뜻이 아니다.

정상 수집 큐의 정확 receipt/corp/FY/basis만 우선한다. API/공개 재시도 횟수나 한도를 초기화하지 않는다. 같은 기간의 일반 이전 보고서를 추정 매핑하지 않는다. 기존 반대 기준의 Source/report/fact는 변경하지 않는다.

검증: 공식 raw transport·두 current8·회사/접수/기준/기간/URI/원문 변경 음성, 정상 API0 수집 저장·실제 audit 출처 감사·summary 매출·반대 기준 JSON 불변·attempts3 보존 격리 DB 2건 통과. 운영 변경은 하지 않았다.
