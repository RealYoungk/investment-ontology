# 수집 완료 후속 검증

범위는 회사별 최근 5개 사업연도 사업보고서와 그보다 최신인 중간보고서 1건이다. 공시 주요정보 28종은 이번 완료 대상에서 제외한다. 기존 공시·금액·출처·재시도 횟수·호출 예산은 보존한다.

## 이번 변경

- 재시도 횟수를 소진한 활성 범위 공시도 기업 화면의 미완료 건수에 포함한다. 재시도 횟수 조건 때문에 미수집 공시가 화면에서 사라지던 문제를 수정했다. 재시도 허용 정책은 그대로다.
- 검증된 공식 재무 원문 등록은 221개 구분까지 확대했다. 추가 원문은 연결·별도와 회사·회계기간을 각각 검증한다. 핵심 계정 복구는 전체 재무제표 수집 완료를 뜻하지 않는다. 인쇄되지 않은 금액을 0이나 합산값으로 만들지 않는다.
- 최신 시세 날짜의 가격 또는 지수 장부가 빠져 있으면 정상 이어받기를 서버 시작 시 예약한다. 기존 예산 대기 예약, 실행 중 작업, 사용자 취소를 보존한다. 공공 API의 게시 지연·휴장일 판정은 기존 수집기가 처리하며 누락 날짜를 임의 휴장일로 기록하지 않는다.
- 기존 기업 연결에서도 DART 법인번호와 시세 법인번호가 충돌하는 경우를 수집 실패 사유로 드러낸다. 기존 연결과 원본 식별자·출처는 변경하지 않는다. 신규 마스터에 대한 유일한 정확 일치 연결은 API 호출 없이 정상 내부 작업으로 처리한다.

## 완료 판정

배포 전 운영 조회에서 활성 정기보고서 범위는 15,289건, 실패 기간은 174건, 미수집 연결·별도 구분은 271건이었다. 이는 배포 후 결과가 아니다. 배포 후 정상 수집 결과를 다시 조회해야 한다.

정기보고서가 아직 식별되지 않은 14개 기업은 위 범위의 분모 밖에 있다. 해당 회사의 감사보고서·투자설명서·공식 운용보고서 원문이 존재한다는 확인은 재무 금액 추출 완료와 다르다. 원문 일부만 읽었으면 전체 문서 검토로 표시하지 않는다. 모회사 원문을 신설 회사의 재무보고서로 붙이지 않는다.

일반 6계정 자료에 대한 미승인 부분 저장은 계속 차단한다. 원문 내부 금액 충돌, 현금 범위 차이, 기업 또는 기간 확인 실패를 수집 완료로 바꾸지 않는다. 코드 검증 통과, 원문 확보, 부분 계정 복구, 운영 전체 수집 완료는 별도로 판단한다.

## 검증 증거

최신 시세 예약·기존 연결 검증·생성 코드 등록의 집중 검증 25개가 통과했다. 추가 3개 재무 원문의 정상 캐시 수집은 격리 테스트 DB에서 양쪽 승인 구분의 저장과 기존 횟수·출처 보존을 확인했다. 다음 2개 원문의 정상 수집·재실행 검증도 해당 접수의 승인 구분 4개 사례에서 통과했다. 공식 별도 원문의 저장·출처 보존 검증 2개와 재시작 예약·취소 검증 2개가 통과했다. 최종 커밋의 전체 검증 및 운영 배포·저장 확인은 별도 릴리스 기록으로 확정한다.
