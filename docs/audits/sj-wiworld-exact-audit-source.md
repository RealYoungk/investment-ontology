정확한 두 별도 원문만 지원합니다. SJ켐 20260326000605(2025.12), 위월드 20240320000531(2023.12)의 공식 첨부 목록은 같은 접수 감사보고서로 고유하게 연결됩니다. 본문 숫자는 변경하지 않고 감사보고서 실제 노드 URI·원문 SHA와 표지·전체 연간기간·직접 핵심계정·재무상태표 등식·자본변동표 대조를 검증합니다. 저장 출처는 감사보고서 실제 노드이며 본문 오류를 고친 것으로 표현하지 않습니다.

연결 원문은 두 회사 모두 정확한 제2절에 순수 `- 해당사항 없습니다.` 문구만 있습니다(SJ켐은 하이픈 뒤 공백 없음). 원문 fixture와 URI/SHA를 보존했습니다. 공개 시도 2의 정상 경로는 typed 비작성 Source를 저장합니다. 공개 시도 3의 기존 연결 API 자료없음 상태는 그대로 보존하며 새 연결 Source를 저장했다는 주장을 하지 않습니다. 후자는 별도 감사원문 immutable cache 1회만 복구합니다. 새로운 자료없음 추정 조건·카운터 초기화·일반 재시도 상향은 없습니다.
