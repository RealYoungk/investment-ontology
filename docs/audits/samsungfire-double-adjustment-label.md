# 삼성화재 전체 순익 조정주석 라벨

삼성화재 2021/2022 별도 공식 원문(20220310001159/20230309000772)의 전체 영업수익 총행, 직접 당기순익 금액 셀 및 CE 전체 순익·자본을 독립 검산한다. `lll.`와 `Vlll.`은 실제 인쇄된 유한 행 순번으로만 분리한다. 대손준비금과 비상위험준비금 반영 후 조정이익 두 괄호는 정확한 원화 당기/전기 문법만 계정명 장식으로 인식하며 주석 속 숫자는 재무 금액으로 사용하지 않는다.

실제 순익은 2021년 1,092,584,640,430원, 2022년 1,141,384,898,627원이다. 조정이익과 서로 다르며 직접 금액 셀에서 읽는다. 전체 영업수익은 각각 23,967,024,499,195원, 25,210,977,366,869원으로 실제 총행에 인쇄되어 있다. 보험영업수익과 투자영업수익을 합산하지 않는다. 원래 영업수익 계정명을 그대로 보존한다.

회사·접수·연간기간·현재 열·독립 단위·BS회계식·CE전체순익/자본 검산을 유지한다. 은행 매출 총행 미확보 6계정 경로는 활성화하지 않는다. Dart와 SQL은 동일한 finite regex를 공유한다. 정상 API/과거 Source/attempt/반대 basis는 변경하지 않는다.

검증: 공식 현재셀 원문 추출 대조, 순수 회귀71 및 신규 registry 경계41 PASS, 정상큐·cache publicAttempt3/replay DB2 PASS, 저장8행·인쇄 계정명·SQL/Dart 순익/매출 동일·Source SHA/URI·주석숫자 불사용·반대 basis synthetic sentinel·API0·counter불변 확인. 테스트 PG 종료 확인. CFS는 이 OFS2 후보에서 숫자 대체하거나 검증 완료로 주장하지 않는다.
