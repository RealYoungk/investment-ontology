# 알파인더 화면 문구

2026-10-01 사용자 요청: 처음 온 사람도 서비스 목적과 다음 행동을 바로 이해할 수 있도록 쉬운 말과 친근한 해요체 사용.

- 첫 화면에서 국내 상장기업을 찾고 비교하는 서비스임을 설명한다.
- 기능 명사보다 사용자 행동을 쓴다: 재무 조건 → 숫자로 찾기, 사업·제품 → 하는 일로 찾기.
- 숫자로 찾기에는 매출·이익·배당 예시를, 하는 일로 찾기에는 제품·공정 예시를 붙인다.
- 짧은 버튼은 행동으로 표현한다: 조건 바꾸기, 조건 지우기, 다시 불러오기.
- PER·ROE와 회계 기준은 정확한 이름을 유지한다. 쉬운 표현으로 바꾸면서 계산 의미를 바꾸지 않는다.
- 자료 없음과 수집 중을 구별한다. 실제 진행 중이 아니면 확인 중이라고 쓰지 않는다.
- 출처, 분류 범위, 불확실성은 숨기지 않고 쉬운 말로 설명한다. 투자 성과를 약속하지 않는다.
- 오류에는 사용자가 할 수 있는 다음 행동을 제공한다. 내부 예외 문자열을 그대로 노출하지 않는다.

이번 적용 범위: 홈·서비스 소개, 기업 찾기 공통 헤더·탭, 숫자로 찾기 안내·예시 조건·오류·빈 결과, 하는 일로 찾기 안내·분류 범위·출처, 비교 시작 안내, 검색 바로가기.

## 2026-10-01 기업 찾기 선택지 노출
- 사용자 피드백: 드롭다운은 선택지가 눈에 들어오지 않으며 기능과 설명이 과다하다. 전체 찾기 예시 13개를 네 그룹의 버튼으로 노출. 반복 소개 문구 제거, 상세 설명은 선택 항목의 도움말로 이동. 실제 적용 수치는 삭제 가능한 칩으로 유지.
- 숫자 직접 수정과 프리셋의 기존 수치/조건 교체 동작은 유지. 기본 요청 limit=10, 이전/다음 페이지, 조건 변경 시 첫 페이지로 복귀. 서버 전체 지표 캐시 계산 비용은 그대로이며 전송/렌더링 범위만 축소.
- 하는 일로 찾기: KSIC 대분류를 사용자용 탐색 묶음으로 재배치. 기업 필터 코드는 보존, 공식 명칭은 tooltip. 반도체 세부 탐색은 IT·전자 안으로 통합. 이것은 탐색 이름/구조 변경이며 전 업종 제품 taxonomy가 완성된 것은 아니다.
- UX 근거(기본 웹 검색 + Exa 병행, 원문 확인): NN/g [Does Your Form Really Need a Dropdown List?](https://www.nngroup.com/articles/dropdown-list/) (2026-07-17): 숨겨진 선택지의 발견성과 상호작용 비용. [Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/) (2006-12-03): 세부 기능을 필요할 때 공개. 13개 버튼의 그룹화는 우리 화면에 대한 설계 판단이며 사용자 실험 결과가 아니다.
