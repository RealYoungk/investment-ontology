# 공시 선택 메뉴 정리

사용자 화면의 자금조달·자사주·임원/주주·주요주주 메뉴는 선택 버튼을 반폭 SizedBox와 Material 테두리로 감싸고, 전체 폭 ghost 버튼 안에 여러 줄 요약을 넣어 카드처럼 보였다. 빈 상태가 네 메뉴와 선택 본문에서 반복됐다.

ResearchSection의 메뉴를 직접 ShadTabs/ShadTab으로 바꿨다. 선택 항목의 요약만 본문 위에 표시하고, 빈 공시 안내는 본문에 한 번 표시한다. 가로 폭이 좁으면 기본 탭 스크롤을 사용한다. 데이터 조회·보고 목록·관리자 체크·출처·미수집/검증된 빈 상태 구분은 유지한다. 선택 변경 시 기존 limit/series/error 초기화를 유지한다.

분석 오류 없음. 관련 테스트 16개 통과. 320/1045px에서 네 메뉴의 높이 70px 미만과 반복된 빈 안내 제거를 검증했고, 메뉴 전환·수집 대기 재시도·보유 변화 해석·출처 회귀를 확인했다. 운영 배포는 하지 않았다.

최종 Web release 빌드 통과(65.5초). 허용된 로컬 8110 프리뷰에서 1045px 아크릴 공시 탭의 간결한 메뉴, 빈 결과 한 번 표시, 임원·주주 선택 시 최근 요약과 5개 실제 보고 목록 표시를 확인했다. 화면 증거는 outputs/design/disclosure-layout-2026-10-05/desktop.jpg. 기존 개발 앱에는 앞선 app_auth compiler summary 캐시 오류가 남아 있어 최종 빌드로 검증했다. 임시 프리뷰·탭·viewport는 정리했다.
