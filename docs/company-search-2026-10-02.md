# 기업 이름 검색 개선

company.list는 검색어가 있으면 상장/시장/업종 조건을 통과한 기업의 검색 키를 비교한다. 원래 이름은 보존하고 대소문자, 공백, 하이픈 및 법인 표기를 정규화한다. 영문 회사명의 한글 글자 발음과 S-OIL의 에스오일 발음을 지원한다. 시총 정렬 검색에서는 공식 이름/한글 발음의 완전 일치와 앞부분 일치를 먼저 표시하고 영문명, 이름 부분 일치, 대표자 순으로 평가한 뒤 동순위에서 시총을 사용한다. 검색어 없는 목록의 기존 DB 정렬/페이지 경로는 유지한다.

로컬 실제 API 확인: s → S-Oil(주) 4번째, 에스 → 6번째; s-oil/soil/s oil/에스오일/010950 → 해당 기업 단독. 검색 및 생성 코드 등록 5개 테스트 통과, 대상 정적 분석 정상. 기존 company 통합 테스트는 생성 테스트 도구의 ephemeralDatabase와 serverpod_test 4.0.0 불일치로 실행 불가. 생성 파일은 수동 수정하지 않았다. Flutter DTD 연결은 성공했으나 driver 응답 timeout으로 모바일 입력/탭 검증은 미완료. 운영 배포 없음.

## 일반화 후속

기업별 S-OIL 분기를 제거했다. 한글 글자 발음 ↔ 영문 약칭의 공통 검색 키와 명칭 단어 사전(oil/bio/tech/holdings/network/networks/bank)을 사용한다. 긴 발음 우선으로 에이치/에이 충돌을 피하고 약칭 사이의 앤/앤드는 &와 동일하게 비교한다. 법인 표기·공백·대소문자·하이픈·전각 ASCII 차이를 흡수하며 명시적인 초성 입력만 초성 검색한다. 임의 영문 단어의 발음, 오타, 옛 회사명은 추정하지 않는다. 전체 결과가 8개를 넘으면 검색어를 보존한 기업 목록으로 이동하는 버튼을 제공한다. 기업별 특례 대신 SK/LG/HD/DB/KT&G와 가상 혼합 이름·초성·전각·오탐 방지 회귀를 추가했다.
