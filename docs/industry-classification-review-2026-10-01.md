# 업종 탐색 분류 재검토

상태: 현재 구현 진단과 설계 제안. 새 분류체계 적용 완료 또는 사용자 승인 기록이 아니다.

## 현재 구조는 왜 납득하기 어려운가

1. `AllIndustryCatalog`는 공시 규칙 결과와 KSIC 등록 분류를 같은 `role/groupName` 축으로 합친다. 제품 종류(완제 의약품), 사업 모델(위탁생산), 등록 코드가 동일 단계 버튼으로 나타난다.
2. 같은 산업 안에서 한 기업의 공시 규칙이 하나라도 맞으면 등록 업종 fallback을 대체한다. 규칙 추출 성공 여부가 회사의 분류 위치를 바꾼다. 이는 산업 분류 원칙이 아니다.
3. 전체 2,759개 기업 중 159개에만 공시 기반 활동이 있는 상태다. 374개 그룹/584개 키는 세분화의 정확성 또는 비교 가능성 증거가 아니다.
4. 표제어 수를 늘리거나 익숙한 용어로 바꾸는 것으로 해결되지 않는다. 포함·제외 정의, 서로 다른 분류 축, 기업 배정 근거가 먼저 필요하다.

## 공식 자료에서 확인한 것

MSCI·S&P의 GICS 방법론 원문 April 2026을 기본 웹과 Exa로 재조회했다. URL 날짜가 본문 버전과 다르므로 본문을 기준으로 삼았다.

https://www.msci.com/indexes/documents/methodology/1_MSCI_Global_Industry_Classification_Standard_GICS_Methodology_20250220.pdf

- 1.1/1.2: 산업을 네 단계로 조직한다.
- 3.1: 주된 사업을 매출 중심으로 판단하고 이익과 시장 인식도 고려한다. 단순 키워드 존재로 기업을 배정하는 체계가 아니다.
- 352010/352020/352030: Biotechnology, Pharmaceuticals, Life Sciences Tools & Services를 구분한다. 의료장비·서비스는 별도 산업군이다.
- 45301010/45301020: 반도체 소재·장비와 반도체를 구분한다. 식각·증착이나 특정 치료 기술까지의 탐색을 그대로 제공하지 않는다.

공식 회사별 GICS 데이터의 사용 권한/확보 여부는 확인하지 않았다. 자체 추론 또는 KSIC 변환 결과를 공식 GICS 배정이라고 표시할 수 없다.

## 제안: 산업 위치와 사업 탐색 조건 분리

| 계층 | 질문 | 운영 원칙 |
|---|---|---|
| 산업 | 이 기업의 중심 사업은 어디에 속하나? | 표준 체계 정의·코드·버전 보존. 공식 배정과 자체 추정 분리. 주력 판정이 불가능하면 확인 전으로 남긴다. |
| 사업 모델 | 무엇을 제공하고 어떤 방식으로 수익을 얻나? | 직접 제품 판매, 개발·라이선스, 위탁생산 등 업종별 정의. 자체 탐색 분류임을 표시. |
| 제품·기술·공정 | 어떤 구체적 사업에서 서로 비교할 수 있나? | 분리된 필터. 복수 활동 가능. 개발·생산·서비스 제공 역할을 보존. |
| 기업 근거 | 왜 이 조건에 포함되나? | 해당 회사의 공시 문장/표, 보고기간, 역할, 가능하면 매출 비중. 단어 출현만으로 추가하지 않는다. |

예: 증착은 반도체 장비의 공정 조건이다. 설계 IP와 같은 단계의 사업 모델 항목으로 합치지 않는다. 바이오의 특정 기술도 사업 모델과 별도 축이며 사용자가 예로 든 단어를 곧바로 분류 항목으로 확정하지 않는다.

각 분류를 제안하려면 최소한 정의, 포함 조건, 제외 조건, 실재 기업 사례와 원문 근거, 경계 사례, 현재 데이터 커버리지를 함께 제시한다. 먼저 반도체/헬스케어 두 산업으로 일관성을 검증하고 나서 전체 업종으로 확장하는 설계가 타당하다. 이 순서는 제안이며 이번 요청에서 회사별 전체 재분류를 실행하지 않았다.

## 이번 적용

- 업종 탐색의 검색창 및 문자열 매칭 제거. 과거 URL의 `q`는 결과를 제한하지 않으며 다음 필터 조작 시 URL에서도 제거된다.
- 기존 공정/제품/역할 선택은 유지한다. 사용자가 선택한 조건을 임의로 모두 해제하지 않는다.
- 정적 분석 통과, 모바일 320px/데스크톱 1280px 위젯 회귀 3개 통과.
- 새 taxonomy를 임의로 다시 배정하지 않았다. 현재 분류를 공식 GICS라고 설명하지 않는다.
