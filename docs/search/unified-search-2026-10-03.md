# 통합검색 확장과 개선 기록

사용자 승인: 상단 통합검색을 가능한 데이터와 기능으로 확장하고 결과 없음/불만족 검색을 개선에 활용한다.

## 구현한 범위

기존 기업/인물 RPC와 URL/키보드 선택 유지. 검색원별 독립 처리로 한 RPC 실패가 다른 결과를 지우지 않는다. 일부 실패는 안내하고, 모든 원격 조회 실패+로컬 결과 없음은 정상 0건으로 처리하지 않는다. 로컬 목적지 카탈로그: 메뉴, 개별 시장지표(환율·국채·브렌트·WTI)와 별칭, 성장/수익성/배당 필터, 자동차 업종, 관심종목·알림. 제목 일치 우선. 숨긴 테마는 노출하지 않는다. 공시 검색으로 알림함을 제안하는 것은 공시 원문 검색 구현이 아니다.

## 다음 서버 구현 명세 — 아직 수집하지 않음

검색 품질 기록은 서버 저장이 필요하며 이번 슬라이스에는 원문 로그를 추가하지 않았다. SearchEvent: random requestId, normalizedTerm(최대80자), outcome(success/partial/error), sourceCounts, latencyBucket, selectedKind, reformulated flag. 계정ID/IP/이메일/인물 식별 세션 추적은 저장하지 않는다. 이메일·전화·주민등록 형태, 긴 숫자, URL은 원문 저장 대상 제외. 질의 해시도 익명성 보장이 아니므로 원문과 같은 보관 규칙 적용. 원문14일 삭제, 집계90일 삭제를 예약 처리하며 관리자 전용 집계 조회. 선택 이벤트는 결과 문서번호/계좌/개인정보 대신 결과 종류만 기록. 임의 키 입력마다 기록하지 않고 debounce 완료한 최신 응답만 기록한다. 요청 오류와 정상0건은 분리한다. 이벤트 실패는 검색 결과에 영향을 주지 않는다. 요청 크기/빈도 제한과 관리자 접근 테스트가 필수.

개선 대시보드: 0건 질의 빈도, 부분/전체 실패율, 선택률, 재검색률. 클릭 없음은 불만족 확정이 아니라 후보 신호. 먼저 별칭/띄어쓰기/한영명 지원, 다음 산업/정기공시의 서버 검색을 추가한다. 원본 금융 수치나 공개 읽기/개인 인증 경계는 변경하지 않는다.

## 미해결

기업 API 영문명/약칭/종목코드 실제 커버리지, 산업과 공시 검색의 원본 범위/인덱스, 개인정보 탐지의 누락률, 동의/안내 문구와 삭제 검증. 테마는 현재 route redirect로 숨겨진 기능. 수집 스키마/마이그레이션·서버 API·관리 화면을 구현한 뒤에만 검색 기록 활성화.
