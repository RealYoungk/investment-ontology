## 남은 범위

실제 로그인 계정의 관심기업 가격/계정 전환은 브라우저에서 미검증. 기존 WatchlistStore의 계정 경계와 신규 quote epoch를 사용했으나 로그인 테스트를 완료했다고 주장하지 않는다. 경제 일정과 업종 일별 수익률은 데이터 연결 없이 표시하지 않는다. 작은 추이선은 관측 순서 간격으로 그리므로 상세의 실제 날짜 축과 구분하며, 큰 날짜 공백을 자동 단절하는 정책은 후속 보강 대상. 전체 앱 모든 화면의 회귀/OS IME/VoiceOver를 검증한 것은 아니다. 로그인 시세/계정 경계 테스트와 작은 선 날짜 좌표 개선이 다음 검증 단계다.

후속 실제 브라우저 로그 확인에서 hot restart 중 disposed EngineFlutterView 오류와 메뉴 닫기 애니메이션의 1px 임시 제약으로 인한 overflow를 발견했다. _DeskNavigation은 전환 프레임의 거의 0 크기 영역에 전체 메뉴를 배치하지 않도록 수정했다. hot_restart 후 새 개발 앱 탭의 390px 열기/닫기를 재검증했으며 해당 탭 error 로그는 없었다. 이 구간 오류를 숨기거나 최초 실행을 무오류로 판정하지 않는다.
