# 재무표 계약과 shad 표 적용 판단 — 2026-10-03

결정: 기본 컨트롤·오버레이는 shad에 의존한다. AppDataTable은 재무 자료를 조합하는 서비스 전용 표로 유지한다. shad 기본 표의 API를 복제하거나 패키지에 새 표 구현을 추가하지 않는다.

## 확인한 근거

고정한 shad 0.99.4의 `lib/src/components/table.dart`는 셀 높이 기본값 48(115행), 셀 Container에 해당 높이 적용(142행), 행 span 기본값 FixedTableSpanExtent(48)(593행)이다. rowSpanExtent를 지정할 수 있지만 임의의 원문 위젯의 intrinsic height를 자동 측정하는 계약은 없다. 기본 ShadDataTable은 갤러리의 짧은 목록에 사용한다.

현재 AppDataTable은 RenderTable의 내용 높이를 사용하고, 숫자·날짜의 최소 폭과 한 줄 표시를 지킨다. 내용이 좁으면 flex 근거 열이 나머지 폭을 사용하고, 넓으면 하나의 수평 ScrollView가 넘치는 열을 맡는다. 긴 공시 근거를 일률적으로 48px에 넣으면 내용을 가릴 수 있다. 이번 작업에서 수치·단위·연결/별도·원천·결측 의미는 바꾸지 않았다.

## 이전 전 필수 계약

| 계약 | 현재 근거 |
| --- | --- |
| 긴 원문은 생략하지 않고 가변 높이로 표시 | app_data_table_test.dart: 긴 원문 높이 >48, maxLines 제한 없음 |
| 숫자 오른쪽 정렬·결측은 0으로 변환하지 않음 | 같은 테스트: numeric TextAlign.right, null은 — |
| 넓은 화면은 전체 폭 사용·근거 열에 나머지 폭 | 기존 flex 열 회귀 검사 |
| 좁은 화면은 열 폭 유지·수평 스크롤 | 기존 400px 초과 열 회귀 검사 |
| 재무 계산·연결/별도·원문 값 hover·결측 사유 보존 | 기존 금융/지표/스크리너 테스트와 실제 삼성전자 재무 표 열기 |
| 수평/수직 wheel·touch ownership, 1천행 성능 | 별도 실제 입력/성능 검증 필요; 완료로 표시하지 않음 |

후속 shad 표 이전은 실제 사용처별 행 높이/원문/선택/정렬/스크롤 계약을 먼저 만족해야 한다. 공시 표를 단순한 고정 높이 목록으로 일괄 치환하지 않는다. 차트·관계망·공시 설명은 서비스 조합으로 남는다.
