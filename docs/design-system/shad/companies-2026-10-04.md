## 후속 UI 확정

검색·시장·업종은 하나의 필터 패널로 묶고 정렬은 표 컬럼 헤더로 이동했다. 종목·회사명·시가총액·설립일은 직접 ShadButton/Tooltip으로 서버 정렬을 연결하며, 비선택 컬럼에는 ↕, 선택 컬럼에는 방향 화살표와 강조를 표시한다. 서버가 지원하는 기존 방향(시가총액 내림차순, 나머지 오름차순)을 유지한다. 상단 기업 수/출처와 표 앞의 중복 결과 안내는 제거했다. 전체 개수는 하단 범위 안내에 남는다.

표 너비는 고정 열 합계에서 나머지를 회사명/업종에 배분해 필터 패널과 같은 전체 폭을 사용한다. ShadPagination의 페이지 번호를 URL과 연결하고 모바일은 번호 창을 줄인다. 빈 결과는 직접 ShadEmpty를 사용한다. ShadDataTable은 로컬 행 정렬/페이징 controller를 제공하므로 전체 기업 대상 서버 정렬을 유지하는 ShadTable을 사용한다.
