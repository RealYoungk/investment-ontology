# shad 서비스 디자인 개편 — 2026-10-03

사용자 요청: 전체 앱 디자인을 shad 기준으로 이관하고, 차트 등 없는 요소는 서비스 시스템으로 만들며 정보 배치를 전면 정리한다. 기존 Ant 폐기/정확 shad 의존 결정을 유지한다. 다른 작업의 미커밋 서버·생성 client·결제·운영 데이터 변경을 정리하지 않았다. 서버 직접 시작, 인증 우회, 금융 데이터 수정, 운영 배포를 수행하지 않았다.

## 이번 구현

1. 서비스 색·한국어/숫자 글꼴·Shad typography를 shad_theme.dart로 모았다. 이전 Research Desk import는 호환 이름만 남는다. upstream 기본 API 사용을 유지했다.
2. AppLayout에 화면/패널/표 밀도를 명시했다. PageHeading의 heading semantics, 섹션 제목 역할을 정리했다. 재무표의 두꺼운 선을 중립적인 머리글과 얇은 구분선으로 바꾸고 행 높이는 고정하지 않았다.
3. CompanyDataCard를 포함한 일반 연구 블록을 실제 ShadCard 기반 DataPanel로 이관했다. 중첩 DataPanel은 박스를 추가하지 않는다. 사업 안내·공시·지분 변화·계정·스크리너·관계망·결제의 중립 패널 후보를 검토하고 적용했다. `neutral-panels-applied.json`은 자동 이관한 위치만 기록한다. 상태색, 행, 그림 도형은 제외했다. 멤버십 플랜은 직접 ShadCard/Badge를 쓰며 관심기업 수 강조의 내부 흰 박스를 제거했다.
4. 홈의 기업 검색/산업 진입을 시장·공시보다 앞에 놓고 산업 블록의 흰 행 박스를 제거했다.
5. 범주 차트에 focus ring, 방향키/Home/End/Escape, 선택 값/단위/결측 이유와 custom semantics action을 추가했다. Flutter Web의 숫자 slider 변환에서 0/1/2가 노출되는 문제를 실제 Chrome에서 확인한 뒤 기간 action으로 정리했다. tooltip 텍스트와 semantics value를 중복 낭독하지 않도록 했다.
6. 자유 관계망과 방향성 도식의 렌더링/표시 모델/결정적 배치를 design/components/charts로 분리했다. 원본 DTO의 금융 포맷·확인/추정·탐색은 feature 어댑터가 유지한다. 이름이 가려진 노드도 semantic 이름/동작을 제공한다. 자유 관계망 아래쪽 이름을 위한 여백을 확보했다.
7. StatusDot은 OS 동작 줄이기 설정에서 반복 pulse를 멈춘다. 서버 없이 동일 테마·합성 데이터로 여는 design_preview.dart와 실제 서비스 `/design` 갤러리를 추가/확장했다.

공통 규칙과 예제 진입점은 [system.md](system.md). 이것은 모든 upstream 컴포넌트를 별도로 복제했다는 선언이 아니다. shad의 전체 패키지를 고정 의존하고 실제 사용하는 범위와 서비스 표시 계약을 시스템화했다.

## 원본과 경계 확인

- `vendor-check.json`: published 0.99.4 Dart 300개 중 input.dart 한 파일만 다름. 이번 작업에서 vendor 패치 확장 없음. 기존 MIT/OFL/폰트 provenance 유지.
- `component-boundaries.json`: upstream component source 45개, 앱의 남은 Material 생성자는 구조/선택 가능한 텍스트 interop용 Material/Scaffold뿐. Core Flutter layout, CustomPaint, Text, Semantics 등은 정상적인 구현 수단이다.
- `ui-inventory.json`: features Dart 139개 전체 소스 참조/장식 위치 목록. 파일을 스캔했다는 사실이 모든 화면/모든 클릭을 검증했다는 뜻은 아니다.
- `design_boundary_test.dart`: 화면의 직접 색/글꼴 참조 금지와 디자인 영역의 서버 DTO/사업 화면 import 금지.

## 검증 증거

`outputs/design/reform/final-tests.log`는 전체 330 pass/기존 원천 스냅샷 2 skip. 마지막 일반 카드/플랜 보정 뒤 관련 25개는 polish-tests.log에서 추가 통과했다. analyzer 오류/경고 0, 기존 사업 코드 info 2. 최종 서비스 web build는 web-build-final.log, 독립 프리뷰는 preview-build.log, 형식 검사는 format.log를 읽는다. 마지막 줄이 성공일 때만 빌드 성공으로 판단한다.

새 회귀는 차트 키보드/결측 원인, 320px 긴 근거와 중첩 카드 하나, 독립 관계망 노드 선택, 방향성 도식의 단위/추정/비연결 선택, 동작 줄이기, 사업 의존 경계를 검사한다. 기존 연결/별도·필터·뒤로가기·인증·결제/관심종목 검사를 삭제하지 않았다.

실제 브라우저 기록은 browser-coverage.json. 화면 이름이 일찍 보인 시도와 실제 데이터/빈 결과를 기다린 시도를 구분한다. 잘못된 shareholderReturn tab은 overview fallback으로 관측했고, 올바른 `returns` URL로 다시 검사했다. 공시 탭의 예상 label `항목`은 현재 사업 화면과 달라 readiness에 실패했으나 `수집 범위에 해당 보고가 없습니다` 상태를 화면으로 확인했다. 이를 로딩 성공 또는 데이터 누락 버그로 오해하지 않는다.

최종 브라우저 기록은 20회 경로 관측을 포함한다. 1440px 기업·시장·시장 지표·스크리너·비교·멤버십·삼성전자 재무/지배구조/주주환원/공시를 열었다. 320px 홈·멤버십·로그인과 익명 계정/관심기업/관리 경로의 접근 제한을 확인했다. 768px 기업 목록은 마지막 재시작 뒤 실제 행까지 확인했다. 390px 홈/재무, 1440px 관계망/시장 지표와 320px 독립 프리뷰도 화면으로 확인했다. 이 기록에는 초기 제목만 준비된 시도가 있으므로 모든 데이터와 상호작용 완료로 읽지 않는다.

독립 프리뷰는 `http://127.0.0.1:8795/`, 서비스 갤러리는 `/design`이다. 실행 재현은 system.md의 design_preview.dart 명령을 따른다. 마지막 MCP hot_restart 성공 후 Flutter 로그는 reload/restart 성공, 서버 로그는 webserver listening/restart 성공이었다. 앱 lib/test 245개 파일의 format 검사에서 변경 0, 신규 이관 도구도 format 적용, git diff --check 통과.

남은 검증: 실계정 이후 관리자·결제·개인 데이터, 모든 인물/보고서 상세의 실제 탐색, 전체 wheel/pinch 조합, OS 한글 IME/VoiceOver, 서비스 다크 모드. 일부 Shad 버튼이 웹 semantic snapshot에서 중첩 button으로 나타나는 점은 기록하며, 외형 검증만으로 접근성 완료를 선언하지 않는다. 이를 해결하려고 문서화된 input.dart 외 vendor 패치를 늘리지 않았다. 기존 공개 금융 값의 정답을 이번 UI 작업으로 검증하지 않았다.

## 사용자 브라우저 피드백 수정

- 내비게이션의 선택 배경을 중복으로 칠하던 Material/DecoratedBox를 정리하고 ShadButton의 기본·hover·focus 모서리에 서비스 radius를 명시했다. 아이콘 반대편에 같은 폭을 예약해 메뉴 텍스트를 버튼 전체 중앙에 정렬했다. 이는 서비스 조합의 문제이며 shad가 강제하는 정렬이 아니다.
- 시장 스크롤 실패의 최초 오류는 SectionLabel의 tooltip 버튼이 Row의 비제한 너비에서 width: double.infinity를 요구한 것이었다. 내용 크기(width: 0)로 변경했다. 뒤따른 semantics assertion을 원인으로 오해하지 않도록 최초 layout 오류를 기준으로 수정했다. 임시 오류 수집 코드와 표 semantics 실험은 제거했다. PageFrame은 독립 ScrollController를 소유하고 primary 공유를 피한다.
- 회귀 테스트는 tooltip 제목+trailing, 차트, 표, semantics 활성 상태의 휠 스크롤과 390/1440px 내비게이션 중앙 정렬을 포함한다. 관련 테스트 15개 및 수정 파일 analyze 통과. 실제 localhost:8100 시장에서 1280px와 1087px 휠 스크롤을 확인했고 깨끗한 세션 콘솔 error 0건이었다. 증거: outputs/design/reform/market-scroll-fixed.png 및 ui-fixes-final-tests.log. 운영 배포는 수행하지 않았다.
