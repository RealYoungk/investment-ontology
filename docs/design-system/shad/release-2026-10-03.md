# shad 및 홈 릴리스 — 2026-10-03

사용자가 검토한 실제 홈 및 shad 전환을 별도 체크아웃에서 분리했다. 원래 작업 트리의 다른 미커밋 변경은 보존한다.

포함: shad 0.99.4+기존 입력 한 파일 패치, 디자인 토큰·서비스 패널·차트, 홈/내비게이션/드로어, 검색 목적지 확장, 홈 및 셸 Lucide 아이콘, 검색 필드 크기 안정화, 기본 ShadSpinner. 최신 main에 이미 포함된 공개 macro.overview API를 사용한다. 서버를 교체하지 않는 웹 릴리스다.

최신 main(703e46d72)에 먼저 반영된 결제·정관·채권·금융 출처·네트워크 기능을 보존했다. 해당 기능의 사업 규칙을 새로 바꾸지 않고 Shad 기본 위젯과 테스트 호스트만 연결했다. 별도 미커밋 서버 변경은 포함하지 않는다. 원본 작업 트리를 변경해 분리하지 않았다. 생성 파일은 별도 체크아웃에서 Serverpod generator로 생성했다. 이 체크아웃에는 개발 서버/시크릿 설정이 없으며 서버는 시작하지 않았다.

NavigationMenu는 직접 링크 및 키보드 이동을 구현한 범위다. 완전한 upstream 호버 팝오버 동등성은 미완료. 실계정·OS IME·스크린리더 전수검증은 완료로 주장하지 않는다. 검색 품질 기록은 활성화하지 않는다.
