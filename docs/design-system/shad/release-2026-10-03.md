# shad 및 홈 릴리스 — 2026-10-03

사용자가 검토한 실제 홈 및 shad 전환을 별도 체크아웃에서 분리했다. 원래 작업 트리의 다른 미커밋 변경은 보존한다.

포함: shad 0.99.4+기존 입력 한 파일 패치, 디자인 토큰·서비스 패널·차트, 홈/내비게이션/드로어, 검색 목적지 확장, 홈 및 셸 Lucide 아이콘, 검색 필드 크기 안정화, 기본 ShadSpinner. 홈에 필요한 공개 macro.overview 모델·API·공식 소스 읽기를 추가했다.

제외: 결제 가격/PG 전환 및 정책, 정관/채권 기능, resilient client. 겹친 결제 UI는 기존 사업 규칙을 유지하는 Shad 기본 위젯 교체만 반영했다. 원본 작업 트리를 변경해 분리하지 않았다. 생성 파일은 별도 체크아웃에서 Serverpod generator로 생성했다. 이 체크아웃에는 개발 서버/시크릿 설정이 없으며 서버는 시작하지 않았다.

NavigationMenu는 직접 링크 및 키보드 이동을 구현한 범위다. 완전한 upstream 호버 팝오버 동등성은 미완료. 실계정·OS IME·스크린리더 전수검증은 완료로 주장하지 않는다. 검색 품질 기록은 활성화하지 않는다.

검증 및 배포 기록은 완료 후 갱신한다.
