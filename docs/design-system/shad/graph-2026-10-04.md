# 관계망 shad 전환 — 2026-10-04

관계망 메뉴 `/graph`와 `/graph/:corpCode`의 검색·설정·모바일 관계 목록을 shad 기준으로 정리했다. DataPanel(ShadCard)에 중심 기업 검색과 단계/노드 토글을 묶고, 비상장·해외 법인 포함은 직접 ShadSwitch를 사용한다. 시작 안내는 ShadAlert, 노드·관계 수는 ShadBadge, 검색 결과와 모바일 관계 행은 ShadButton.ghost다. 그래프 자체는 기존 ResearchGraphCanvas를 유지한다.

검색 중/빈 결과/실패를 구분하고 요청 번호로 늦은 응답을 무시한다. 결과 선택 시 대기 검색과 이전 응답을 무효화한다. 기업 재중심화·관계 그룹/지분율/추정·URL/API/인증 계약은 유지한다.

검증: Flutter 앱 전체 dart analyze 이상 없음. 변경 파일 및 추가 테스트 analyze 이상 없음. format 변경 0, git diff --check 통과. 관계망/디자인 경계 테스트 7개 통과(320px 시작 화면·설정 클릭 포함).

실행 검증 제한: Serverpod MCP hot_restart 호출은 client closed 오류로 완료를 확인하지 못했다. DTD 연결은 최초 성공했지만 이후 URI 조회는 빈 결과였고 driver 연결이 해제됐다. spawn_flutter_app은 시작 요청을 접수했으나 후속 MCP 로그 연결도 실패했다. 브라우저는 준비/연결 지연 후 localhost:8100 연결 거부를 보였다. 실제 데이터 화면·검색 선택·모바일 관계 이동·wheel/pinch는 이번 작업에서 검증 완료하지 않았다. 사용자 serverpod start 복구 후 재확인 필요. 웹 빌드는 시작했으나 이 기록 시점 결과 미확인. 운영 배포 없음.

## 후속 실행 검증 및 정정

사용자가 서버는 이미 실행 중이라고 정정했다. 앞선 MCP client closed/빈 DTD 응답은 서버 중지 증거가 아니다. 재확인에서 localhost 실제 관계 데이터 표시, Dart MCP listDtdUris → connect → driver health ok를 확인했다. Serverpod MCP는 이번에도 응답하지 않아 제한된 대기를 종료했고, Flutter DTD hot_restart/hot_reload는 성공했다.

실제 브라우저: 삼성 검색의 6개 결과 → 삼성SDI 선택 후 URL/관계망 이동, 비상장·해외 포함 switch와 재조회, 390px 관계 목록 확인. 모바일 ShadButton 내부 Row에 폭 제약이 없던 오류를 발견해 Expanded로 제한하고 텍스트를 왼쪽 정렬했다. 최종 모바일 삼성SDI → 코스모신소재 이동 및 실제 주주 지분율/추정 표시 확인. 이미지 outputs/design/shad-graph/mobile-390.png. Driver text entry emulation/frame sync는 원래 상태로 복원했고 viewport override도 해제했다. 수정 이후 DTD runtime errors 없음.

추가 데이터 행 회귀를 포함한 8개 테스트 통과, 변경 파일 analyze 이상 없음. 앞서 시작한 웹 빌드는 exit 0/Built build/web 확인. 이 빌드는 마지막 모바일 행 폭/정렬 보정 이전 산출물이므로 최종 소스의 재빌드와 혼동하지 않는다. 최종 모바일 보정은 VM 테스트와 실제 debug 앱 hot_reload로 확인했다. 전체 wheel/pinch·OS IME/VoiceOver와 운영 배포는 이번 범위에서 확인하지 않았다.
