## 여백·정렬 후속 수정

사용자가 실제 화면의 어색한 여백을 지적하여 두 관리 화면의 간격을 재조정했다. ShadSeparator 기본 margin과 별도 SizedBox가 겹치던 부분에서 margin을 명시적으로 0으로 설정했다. 제목 이후 48px 간격을 24px로 줄이고 카드 내부는 서비스 panelPadding(좁은 화면 16px, 그 외 24px)을 사용한다.

데이터 카드의 제목 영역이 40% 고정 폭을 차지하던 배치를 해제했다. 복잡한 데이터는 제목 다음에 지표를 표시하고, 단순 기업정보는 충분한 폭에서 제목과 값을 나란히 둔다. 지표는 640px 미만에서 세로 배치한다. 재무 저장 상태는 지표 아래 전체 폭의 줄바꿈 행과 설명으로 이동했다. 요약 지표는 가용 폭에 나눠 배치하며 좁으면 세로로 읽는다. 상태·출처 영역의 좌우 선도 본문과 맞췄다.

후속 변경 analyze 이상 없음, 관련 회귀 9개 통과, 웹 빌드 성공(213.1초), format/diff 검사 통과. 로그는 spacing-analyze.log, spacing-tests.log, spacing-build.log. 실제 브라우저에서 데이터 카드 간격 수정과 하단 공시·사업 카드 흐름, 회원 카드의 줄어든 구분선 여백을 확인했다. 마지막 단순 기업정보 가로 배치와 재무 설명 이동의 새 세션 검증은 조회 지연 때문에 제한되었으며, 390px에서 데이터 로딩 중 화면만 관측했으므로 이를 모바일 데이터 검증 완료로 기록하지 않는다. 검증용 viewport를 복원했다. 서버 데이터·접근권한·수집 실행은 변경하지 않았다.
