## 3. 사람이 해야 하는 것

- **AI 관계 추출 키**: `config/passwords.yaml`의 `shared:`에 `anthropicApiKey`를 넣거나 `ANTHROPIC_API_KEY` 환경변수. 없으면 검수 큐가 비어 있습니다. 비용이 들어 자동으로 돌지 않으며, 데이터 화면에서 기업 수를 정해 시작합니다.
- **검수**: `/review`에서 AI가 뽑은 공급·경쟁·제품 관계를 근거 인용을 보고 승인·거절.
- **인물 추정 연결 확인**: 인물 화면에서 "추정"으로 표시된 연결 중 틀린 것은 끊기.
- **테마**: `/themes`에서 직접 정의.

## 4. 알아 둘 것

- 웹 개발 서버가 컴파일 오류 뒤에 옛 코드를 계속 내보내면 (`no routes for location` 등) `serverpod start`를 완전히 껐다 켜야 합니다. hot restart로는 풀리지 않습니다.
- 지분 묶음은 공시(최대주주 명단의 법인 주주, 경영참여 15% 이상 출자)에서 계산한 것이라 공정위 기업집단 지정과 다릅니다. 주요정보가 쌓일수록 묶음이 늘어납니다.
