## 4. 알아 둘 것

- 웹 개발 서버가 컴파일 오류 뒤에 옛 코드를 계속 내보내면 (`no routes for location` 등) `serverpod start`를 완전히 껐다 켜야 합니다. hot restart로는 풀리지 않습니다.
