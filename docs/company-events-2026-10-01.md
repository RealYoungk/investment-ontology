# 기업 변화 타임라인 — 2026-10-01

사용자는 유료 데이터 구독 부담을 줄이고 활용 가능한 공개 정보를 투자자가 기업을 이해할 수 있도록 시각화하기를 요청했다.

## 사용자 피드백 반영 — 개요 노출 철회

공시 제목 나열만으로 무엇이 어떻게 변했는지 알 수 없다는 사용자 지적에 따라 기업 개요에서 타임라인을 제거했다. 저장 공시와 독립 위젯/분류 코드는 보존한다. 아래 구현·검증은 노출 철회 전 기록이다.

재도입 기준: 원천의 구조화된 값 또는 자동 검증 가능한 규칙 추출로 주체·행위·변경 전후·규모·기간을 확인할 것. 지분 변동은 보유 수량/비율의 전후 비교, 자금조달은 종류별 금액과 사용 목적, 자기주식은 계획과 실제 이행을 별도로 표시한다. 결정/정정/철회만으로 거래 완료나 매수·매도를 추정하지 않는다. 필요한 숫자를 확보하지 못하면 제목 목록을 대체 시각화로 내놓지 않는다. 아래 후속 구현으로 연간 주주 보유량 전후 비교를 기업 개요에 추가했다. 공시별 사건 타임라인은 계속 미노출이다.

## 구현

기업 개요의 주가 차트 다음에 `최근 기업에 어떤 변화가 있었나요?` 영역을 추가했다. 기존 공개 조회 `disclosure.recentOf`와 저장된 `DartDisclosure`를 이용한다. 외부 API 호출·DB 변경·새 구독·인증 우회는 없다.

- 최근 최대 50건을 자금조달, 주주환원, 지분 변동, 사업 변화, 실적, 위험 공시, 기타로 분류한다. 정확한 제목 키워드에 따른 탐색 도우미이며 기업의 위험도나 호재/악재 판단이 아니다.
- 월별 타임라인, 주제 필터, 6건 기본 표시와 추가 12건씩 펼침, 제출인·접수일·원문 버튼.
- 정정·철회·결정 상태를 표시한다. 정정 전 공시를 자동 폐기하거나, 결정 공시를 실행 완료로 추정하지 않는다. 동일 접수번호만 중복 제거한다.
- 조회된 날짜 범위와 건수를 표시한다. 건수는 거래 횟수나 금액이 아니다. 빈 목록은 미수집으로, 호출 오류는 재시도로 구분한다.
- 기존 앱 전체 수집 완료 신호로 갱신한다. 기업 전환/동시 요청에서 오래된 응답을 버린다.

## 검증

신규 기능 8개 및 디자인 경계 2개 테스트 통과. 320/768/1280px, 1.4배 글꼴, 분류·정정·철회·접수번호 중복 제거, 필터, 원문 URL, 재시도, 응답 역전, 더 보기 검증.

로컬 삼성전자 실제 저장 공시 4건(2026-09-18~22)으로 PC/390px 타임라인과 지분 필터 확인. 실측 중 최대주주등소유주식변동신고서 분류 누락을 수정하고 회귀 테스트 추가. 원문 버튼에서 DART 접수번호 20260922000524 새 탭 열림 확인. DART 본문 내용 전수 검수는 아니다.

화면: `outputs/company-events/desktop.jpg`, `outputs/company-events/mobile.jpg`. MCP hot restart 성공. `disclosure.recentOf` 서버 응답 성공 로그 확인. 기존 로컬 읽기 전용 DB에 따른 서버 내부 정리 작업 실패 로그는 남아 있으며 이 작업에서 DB 설정은 변경하지 않았다. Flutter 로그의 과거 다른 화면 컴파일 오류와 reload timeout 뒤 재시작 완료 확인.

## 현재 한계와 다음 구현 범위

이번 것은 저장된 공시 제목을 시각적으로 탐색하는 기능이다. DS005 주요사항보고서의 상세 금액·발행 조건·완료 보고를 새로 수집한 것은 아니다. 자금조달 금액 그래프, 전환 가능 주식 수, 자사주 계획 대비 이행률, 임원별 보유수량 차트는 원천 상세 수집·검증 후 연결해야 한다. 따라서 이 화면을 해당 정량 기능까지 모두 완료했다고 보고하지 않는다.

운영 배포는 하지 않았다. 다른 개발 변경과 함께 섞여 있는 작업 트리이므로 검증된 release 절차에 따라 별도로 통합해야 한다.

## 후속 구현 — 연간 주요 주주 보유 변화

`OwnershipChangesSection`을 기업 개요의 사업 지표 다음에 연결했다. 기존 공개 `governance.summary`와 저장 `ShareholderEntry`만 사용한다. 유료 API·새 수집·DB 변경 없음.

- 동일 보고서 행의 기초/기말 주식 수를 두 막대로 비교. 주주별 척도임을 명시하며 서로 다른 주식 종류를 합산하지 않는다.
- 기말−기초 수량, 지분율 차이(%p), 공시 비고, 해당 최대주주 현황의 DART 원문을 표시한다. 연도 선택 및 전체 항목 펼침 지원.
- 합계 제외, 누락/음수 제외 및 제외 개수 표시, 0은 실제 0으로 처리. 보유량 변화를 매수·매도로 추정하지 않는다.
- 실제 삼성전자 FY2025: 홍라희 보통주 97,978,700→87,978,700주(1천만 주 감소), 공시 비고 시간외매매. FY2024 전환 시 117,302,806→97,978,700주로 바뀌는 것을 브라우저 확인.
- 검증: 변경 파일 dart analyze 무문제, 신규 단위/위젯 4개 + 디자인 경계 2개 통과, hot_restart 성공. 실제 390px 화면 확인. 스크린샷 outputs/ownership-changes/.
- 범위: 연간 최대주주·특수관계인 보유 변화만 구현했다. 공시별 최근 거래, 자금조달, 자사주 계획/이행 시각화는 이번 구현에 포함하지 않았다. 운영 배포 없음.

## 기간 명시 및 전 기업 커버리지 점검
- 모든 기업에 공통 위젯 사용. 회사 코드 하드코딩 없음. 기업 전환 시 이전 데이터/기간이 남지 않도록 요청 순번과 로딩 상태를 관리한다.
- CompanyGovernance DTO에 shareholderPeriodStart/End 추가(테이블 변경 없음). 종료일은 해당 최대주주 보고서 settlementDate만 사용. 시작일은 직전 연간 최대주주 보고서 종료일의 다음날로 산정하고 산정 근거를 화면에 명시. 두 종료일의 간격이 366일을 넘으면 시작일 미확인. 단순 1월 1일 추정 없음.
- 실제 API: 삼성전자 2025.01.01~2025.12.31, 금비 2024.10.01~2025.09.30, 모아텍 2025.04.01~2026.03.31, 마크로밀엠브레인 2025.07.01~2026.06.30.
- 로컬 읽기 전용 스냅샷(운영 최신 상태 아님): company.market kospi/kosdaq/konex 총 2,759개, 최신 최대주주 사업보고서에서 비교 가능 2,722개(98.66%). KOSPI 826/831, KOSDAQ 1,789/1,821, KONEX 107/107. 누락 37개는 로컬에 해당 보고서 없음. 원천 미공시/수집 누락 원인은 이 집계만으로 단정하지 않음. SQL scripts/audit/ownership_coverage.sql.
- 전체 기능 적용과 데이터 100% 확보는 구분. 자료 없는 기업은 빈 상태를 표시하며 0으로 만들어 표시하지 않음. 읽기 전용 DB 수집 및 운영 배포는 하지 않았다.
- 서버 기간 경계/생성 등록 6개 + Flutter 기업 전환/누락/모바일/디자인 7개 테스트 통과. 변경 analyze 통과, MCP hot_restart 성공, 삼성전자 브라우저 기간 문구 확인.

## 5개년 추이 + 최신 중간보고서
- 단일 연도 전후 막대를 5개 연속 결산 시점 및 그 이후 최신 중간보고서의 추이로 변경. 지분율/보유 주식 수 전환, 보고서 선택 시 해당 사업연도 기초→기말 및 원문 표시. 같은 공시명·주식 종류로 연결하며 한 보고서에 동일 키가 복수이면 합치지 않고 빈칸 처리. 명칭 변경은 자동 동일인 추정하지 않음.
