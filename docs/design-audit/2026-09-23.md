# 투자자 관점 UI 전수 점검과 개선

범위: 라우터의 화면 유형, 기업 상세 6개 탭, 공시 28종, 재무제표 5종을 실제 브라우저에서 열어 점검했다. 이는 모든 상장사의 모든 데이터 행이나 모든 오류 조합을 검증했다는 뜻은 아니다. 삼성전자·SK하이닉스·한화오션 및 기존 테마/지분 묶음을 표본으로 사용했다.

기준: 기존 홈·소개 페이지의 종이색/명조 제목 유지. 추이·구성·비교를 먼저 보여 주고 원문 표로 대조한다. 단위가 다른 값을 한 축에 섞지 않고 결측을 0으로 바꾸지 않는다. 새 AI 요약은 생성하지 않았다.

## 공시 28종 확인 범위

삼성전자에서 25종: 최대주주 현황, 최대주주 변동현황, 소액주주 현황, 임원 현황, 타법인 출자현황, 사외이사 및 그 변동현황, 배당에 관한 사항, 자기주식 취득 및 처분 현황, 주식의 총수 현황, 직원 현황, 미등기임원 보수현황, 이사·감사 보수(주주총회 승인금액/지급금액 전체/지급금액 유형별), 이사·감사 개인별 보수, 개인별 보수 상위 5인, 회계감사인과 감사의견, 감사용역 체결현황, 비감사용역 계약체결 현황, 채무증권 발행실적, 기업어음증권/단기사채/회사채/신종자본증권/조건부 자본증권 미상환 잔액.

SK하이닉스에서 공모자금·사모자금 사용내역, 한화오션에서 증자(감자) 현황을 추가 확인했다. 삼성전자에서 수치가 없는 잔액 공시는 값 없음 상태 그대로 유지했다. 원천 표의 감사 보수 등 단위가 화면상 불명확한 항목을 임의로 금액 차트로 바꾸지 않았다.

재무제표 5종: 재무상태표, 손익계산서, 포괄손익계산서, 현금흐름표, 자본변동표. 기업 상세의 원문 뷰를 통해 공통 렌더러를 확인했으며 `/reports/:reportId` 직접 주소 진입은 별도 수행하지 않았다.

## 검증

- `dart analyze`: 문제 없음.
- `dart format`: 수정 Dart 파일 포맷 적용.
- `flutter test --no-pub`: 전체 65개 통과. 음수·결측 차트, 트리맵, 표 폭, 재무 계산, 지분 계산, 홈 동선, 로그인·작은 화면 검증 포함.
- `git diff --check`: 통과.
- Serverpod MCP hot reload 적용. 상태 필드 추가 직후 개발 hot reload에서 GlobalKey 초기화 오류를 발견해 hot restart 후 공시 항목 전체를 재확인했다.
- 개발 로그에 다중 탭 응답 지연으로 hot reload/restart timeout 흔적이 있지만, 이후 reload 성공 및 수정 화면의 실제 렌더링을 확인했다. 마지막 확인한 서버 조회들은 성공했다.
- Flutter Driver screenshot은 런타임 RangeError로 실패하여 CUA 브라우저 캡처를 사용했다.

스크린샷은 대화의 도구 출력에 포함된다. 별도 이미지 파일로 저장했다고 주장하지 않는다. 데이터 변경, 외부 게시, 배포, 커밋은 하지 않았다. 기존 서버 development.yaml 변경은 이번 UI 작업 범위에서 제외했다.

### 상단 내비게이션 후속 수정

- 사용자 스크린샷에서 발견된 드롭다운 기준점 오류: Expanded 내부 Row가 남은 폭을 차지하여 메뉴가 버튼에서 멀리 열렸다. Align과 최소 폭 Row로 실제 버튼에 앵커를 제한했다.
- 메뉴는 버튼 아래에 표시하고 디자인 surface/border 토큰을 적용했다. 항목 높이 44, 폭 184–220.
- 관리자 표시는 12px 보조 텍스트로, 검색·로그아웃은 20px 아이콘과 40px 클릭 영역으로 정리했다.
- 실제 브라우저 805px 및 390px에서 메뉴 펼침 캡처, 시장/홈 이동 클릭 확인. 1280px에서 수평 메뉴와 계정 영역 확인 후 원래 viewport 복원.
- 해당 파일 dart analyze, dart format 및 design_boundary_test 2개 통과. 초기 편집 중 문법 오류는 수정 후 hot reload 성공과 화면 반영으로 확인했다.
