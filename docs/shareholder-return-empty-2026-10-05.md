# 아크릴 주주환원 빈 값 확인

운영 API shareholderReturn과 배당 원천 표 캐시를 비교했고 DART 2025년 사업보고서(20260318001538)의 배당 절과 주식 총수 절 원문 HTML을 직접 받았다. DART viewer shell만 읽은 것이 아니라 본문을 받아 확인했다.

- 배당 본문: 2023·2024·2025 결산배당 여부 X, 배당금·수익률·성향 모두 -, 최근 5년 배당 지급 없음 명시. 따라서 해당 연도의 빈 배당 값은 수집된 원문과 일치한다. 적자가 배당 미실시의 확정 원인이라고 추정하지 않았다.
- 주식 총수 본문: 자기주식수/보유비율 -, 취득 및 처분 현황 해당사항 없음. 보통주 발행 및 유통 각 8,030,324주. 종류주식은 보통주 전환 후 없음. API 빈 값은 0으로 저장하지 않았다.
- 2026년 반기보고서(20260814003765) 본문도 추가 확인했다. 2026.06.30 자기주식수 -, 취득·처분 해당사항 없음, 반기 주요 배당지표 - 및 최근 5년 배당 지급 없음이 동일하다. 앱 집계 자체는 아직 사업보고서 기반이며 이 UI 수정으로 반기 수집이 완료된 것은 아니다.

공통 UI 수정: 항목명만 있고 모든 수치가 null인 배당 차트를 만들지 않는다. 어떤 배당 수치가 표에 표시되지 않았는지 한 문단으로 안내한다. 실제 공시 표의 기간만 사용하고 미공시 올해를 빈 칸으로 덧붙이지 않는다. 자기주식 수량이 전부 없으면 차트를 만들지 않고 짧게 안내한다. 주식 총수 표는 기본 접힘이며 보유비율 계산 수치가 없으면 빈 도형을 만들지 않는다. 출처/상세 표 접근은 유지한다. 특정 기업 수동 설명을 앱에 하드코딩하지 않았다.

정확성 경계: DTO의 빈 treasury 리스트만으로 다른 기업도 자기주식이 없다고 단정할 수 없다. 이 화면은 해당사항 없음/미수집을 원문에서 확인하도록 명시한다. 배당 표가 없으면 자료 미확보, 표는 있는데 수치가 없으면 표의 수치 미표기로 구분하며 조회 실패는 재시도 안내를 유지한다. 숫자 0은 정상 차트 값이다.

검증: 변경 범위 정적 분석 오류 없음. 390/1045px null 차트 제거 및 명시적 0 유지와 디자인 경계 테스트 5개 통과. 원천 스냅샷은 outputs/shareholder-return-2026-10-05/. 운영 배포는 수행하지 않았다.
