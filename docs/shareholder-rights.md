## 수집 및 권한

- `CharterEndpoint.startCollection`·`advanceCollection`은 `OntologyAccess.requireAdmin`으로 보호한다. 공개 `summary`·`collectionStatus`·`collectionCoverage`는 쓰기나 API 예산 변경을 하지 않는다.
- `CharterFutureCall`은 기존 공식 검색 인덱스의 공고 원문 XML을 DART API로 받는다. 기업 코드가 정확히 하나 일치하는 XML만 인정한다. 원문 URL·접수번호·SHA256·수신 시각과 변경 전후 전체 텍스트를 저장한다.
- 40건 단위로 진행률과 호출 수를 저장한다. 이미 저장된 접수는 건너뛰며 실패한 것만 다음 실행에서 재취득한다. 호출 예산과 취소를 존중한다.
- 운영에서는 FutureCall로 이어받는다. 개발 서버의 `futureCallExecutionEnabled: false`는 유지한다. 관리자 버튼으로 시작한 실행만 인증된 `advanceCollection` 요청을 연속 호출해 이어받는다. 새 관리자 면제나 자동 작업 활성화는 없다.
- XML 표 구조가 유효하지 않거나 API 파일이 없으면 공식 DART 화면을 기업·접수번호에 다시 묶어 대조한다. 임의 URL과 다른 기업의 자료를 받지 않는다.
- 새 모델·마이그레이션, 유료 AI, 운영 배포는 수행하지 않았다. 현재 결과는 로컬 개발 DB에 저장되어 있다.

## 공통 규칙과 화면

`disclosure/charter_comparison_rules.dart`의 `CharterComparisonRules`를 서버·재현 도구·테스트에서 함께 사용한다.

- 현행/개정안 등 명시적 비교 열, 정관변경일/주요변경사항/변경이유 이력 열을 판독한다. 조문을 손으로 입력하지 않는다.
- 정관과 무관한 표는 명시적 헤더 확인 후 제외한다. 일반 주총 표의 큰 rowspan이나 셀 겹침 때문에 정관 비교 전체가 중단되지 않도록 한다. 실제 대상 비교표 자체의 잘못된 구조를 추측으로 메우지는 않는다.
- PDF 페이지를 넘는 조문을 복원한 뒤 동일 여부를 판단한다. 동일한 조문 제목만 있는 페이지 끝 행을 먼저 버리지 않는다.
- 집중투표 배제 삭제, 이사 임기, 충실의무, 감사위원 분리선출, 전자 주총, 독립이사 명칭, 주식 소각 및 시행 시점은 유한한 규칙으로 설명한다. 소각 조항 삭제를 실제 소각 금지로 해석하지 않는다.
- 그 외 조문은 바뀐 부분 주변의 원문을 발췌해 나란히 보여주고 전체 전후·회사 변경 사유를 펼칠 수 있다. 의미·위험을 임의 생성하지 않는다.
- 기업 개요와 지배구조에 같은 카드가 있다. 수집 기간과 확인 건수를 표시하며 이후 날짜에도 저장 자료를 유지한다. 삼성전자 별도 공식 PDF는 DART 비교가 없을 때만 예비 자료로 쓴다.
- 데이터 화면에 누적 확보 수, 대상/비교표/공고 없음/미확보/목록 미확인 수와 다시 수집 버튼을 둔다. 앱 전체 IngestMonitor의 완료 신호로 다시 읽는다.
- 회사 헤더는 홈페이지·위치·기본정보에 아이콘을 병기하고 좁은 화면에서 간결하게 표시한다.
