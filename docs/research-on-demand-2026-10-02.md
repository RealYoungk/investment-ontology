# 조회 기업의 미수집 DART 공시 캐시

운영 read-only SQL 확인(2026-10-02): DART 당일 사용량 20,001, research_snapshot에는 issuerDocuments만 3건. 자금조달·자사주·임원주주·주요주주 스냅샷은 없음. 정기 재무/주요정보 작업과 별도 경로이며 자동 research 배치 예약이 없어 정기 수집 완료를 기다려도 채워지지 않는다.

research.data는 미수집 DART 네 항목만 고정 API에서 가져와 기존 Source/ResearchSnapshot 저장기를 사용한다. 한 번에 한 기업/항목, 동일 요청 Future 공유, 실패 5분 후 재시도, 저장된 빈 응답 재사용. 조회 우선 경로는 공유 일일 장부 19,900회에서 차단하고 KST 자정 이후 다시 시도한다. 기존 명시적 관리 변경의 권한 검사는 그대로다. 기존 스냅샷의 갱신 및 전 기업 백필은 별도 과제다.

로컬 삼성전자 capital 공개 조회에서 ready·빈 배열과 실제 DART Source 저장을 확인했다. 빈 값이 자료 부재와 다른 상태임을 보존한다. 운영은 변경 전 notCollected 응답을 확인했으며 이 변경을 배포한 증거는 없다.

기본 작업 폴더의 통합 테스트는 CLI4.0.3 생성 helper의 ephemeralDatabase 인자와 serverpod_test4.0.0 불일치로 로딩 실패했다. 최신 main의 격리 워크트리는 올바른 생성 helper를 사용한다. 생성 파일을 손으로 수정하지 않았다. Flutter 대기 재조회·화면 해제 타이머와 기존 화면·디자인 경계 13개 통과.

최신 main 격리 체크아웃: 전체 정적 분석 정상, 공개 조회·예산 차단·관리자 변경 권한·스냅샷 이력 통합 및 생성 등록 4개 통과. 통합 테스트는 임의 기업의 미수집 공급원과 19,900회 예산 차단을 검증하며 외부 DART를 호출하지 않는다.
